# 图片与 SVG 转为可编辑 PPTX

用户要求可编辑 PPT/PPTX 时启用。沿用当前图件的科学内容、版式与文字；单图默认单页、保持宽高比，无需另做演示文稿大纲、套模板或增加动画。

## 先确定编辑对象

- 文字与公式转为原生文本框或富文本，保留上下标、换行与对应对象。
- 规则图形、色块与箭头转为原生形状；复杂矢量轮廓可转为自由形状。按可一起移动的部件分组，提供可辨认的组名；检查导出器是否保留分组和名称，SVG 中的 ID 不保证会出现在 PPT 的选择窗格。
- 已有可靠 SVG 时直接复用，先处理已知伪影。只有位图时按本技能的构形与转绘规则重建，再导出。
- 照片或复杂实测纹理可按用户用途保留为可移动、替换的图片对象；说明其像素内容仍属于图片。若用户要求这些区域也能逐部件编辑，需重建相应几何并说明简化程度。
- 整图作为图片插入时，编辑范围为整张图片；逐部件编辑使用原生形状或文本，并按对象组织完整分组。

## 复用现有导出能力

优先调用宿主可用的 SVG/形状到 DrawingML/PPTX 工具。已安装 EasySlides 完整运行时时，可复用其 `scripts/svg_to_pptx.py` 的原生模式；先定位实际安装目录并查看 CLI 参数。确认运行时可调用，使用当前宿主的实际路径。

在任务输出目录建立导出副本：

```text
<project>/svg_output/01_figure.svg
```

已有 EasySlides 工具的调用示例：

```powershell
python "<easyslides-root>/scripts/svg_to_pptx.py" "<project>" --only native -o "<project>/figure-editable.pptx" -t none -a none --no-notes
```

`native` 为原生 DrawingML 输出；`legacy` 为 SVG 图片模式，交付时区分。宿主缺少该工具时检查其他已装原生导出能力；少量图形可用现有 PPTX 库建立原生文本和形状，再按本节验收。按当前图补必要适配即可。目标依然是用户需要的可编辑 PPTX；具体阻塞与替代取舍按 [工具缺失后的处理](svg-handbook.md#recover) 解决，已完成 SVG 可作为中间成果交付。

## 保真与操作验证

- SVG 到 PPTX 可能改变字体度量、上下标位置、渐变坐标、透明度、裁剪及虚线；依据实际 PPT 渲染修复导出副本，不仅查看 SVG 预览。渐变在小色块上重新拉伸或产生补丁时，为该对象重映射色标，或用等效原生填充表达。
- 组图含嵌套 `<svg>` 时，先核对导出日志和 PPT 中各面板是否存在。本地导出曾跳过嵌套视口，只留下标签；在导出副本中按 viewBox、视口位置和 preserveAspectRatio 换算等效组变换，核对裁剪与继承样式，再用实际渲染比较。原 SVG 保留，其他视口模式按其实际规则处理。
- 导出后的部件偏离连接位置时，回查祖先组的复合变换。本地玉米案例的穗与幼株根系在 PPT 中发生偏移，已在副本中将对应仿射变换写入路径坐标并保留语义分组。非均匀缩放还需核对描边，渐变、裁剪与共享引用按实际依赖处理；转换后看实际 PPT 中的连接位置。
- 使用当前 EasySlides 导出器保留选择窗格名称时，可给已有语义组设置 `data-easyslides-instance`，值沿用唯一部件 ID；导出后核对实际组名和成员。普通 SVG 的 `id` 在该导出器中可能仅得到通用的 Group 名称。
- 导出前检查对象是否已按语义重建：逐个主要对象核对其几何、成员和编辑归属。若一个简单对象仍由无意义杂色色区拼成，先重建它，再导出。仅在保持层叠、填充规则与编辑粒度的前提下合并同部件内相邻同样式轮廓，跨对象的同色路径按各自归属保留。已验证的 SVG 源稿保留。
- 做一次包内结构检查，确认要求可编辑的区域使用原生形状/文本，并记录图片对象的实际范围。实际编辑另做一次代表性操作。
- 有目标应用时，在副本中打开 PPT，修改一处代表性文字，并移动一个包含多个子部件的语义对象，确认成员一起移动；保存重开后确认分组、成员关系与修改仍在。接口遍历未找到嵌套组时，先在测试副本中展开必要的上层组合，核对目标组及成员；据此判断目标组是否完整。只有实际编辑失败才修复导出副本并复查。操作现有 PowerPoint 会话时只关闭本任务打开的文稿。
- 自动操作部件时使用稳定 ID 或明确的父组范围定位；多个对象可以有相同显示文字，选中后核对其父组与成员。对不熟悉的选择、分组或变换接口，先在副本的一处对象上验证，再批量执行；重试前确认失败位于绘图、导出还是验证代码，避免反复重画、导出或重组整图。
- 未实测目标应用时如实报告“已导出原生对象，应用内编辑未验证”。按本次实际测试的对象和特性报告结果。

默认交付 `.pptx` 与一张实际 PPT 渲染预览，简述可编辑范围、必要简化和实测情况；用户需要时附 SVG 源稿。普通单图不增加逐部件操作测试、额外格式或多轮审查。
