# 轻量回归：质量、总耗时、修正量

仅用于用户要求的模型/路线对比、skill 改版验证及能力记录维护。普通画图不跑此套件，不自动安装模型或启动多模型。

## 可复用的小样本

[cases.json](../evals/cases.json) 含照片个体、规则设施、植物轮廓、局部编辑，以及科学空间/流路表达和生成图转绘案例。图像使用用户授权的本地附件；套件只存输入键，不捆绑私人照片。缺图或缺科学内容依据记 skipped/missing_input，保留具体缺项。描述题可直接执行。

同图重复用于检查重复性，不同姿态和对象用于检查泛化。后续用户提供并授权的不同姿态/对象可加入，不为凑覆盖抓取外部照片。评测中用过的图标记 seen；评估新题能力时另留未见样本。

## 只改变正在测试的变量

- **模型比较**：同图/描述、skill 快照、任务目标、工具、预算和推理档位（若均支持），新上下文各跑一遍；模型 ID 是主要变量。各模型记录实际推理设置与资源消耗。
- **路线比较**：固定模型与上述条件，比较直接构形与针对一种已观察缺陷的辅助。明确辅助是否提供人工锚点/参考资产及准备时间，将外部辅助与模型自身操作分别记录。
- **skill 效果**：固定模型与任务，比较旧/新版本或无/有 skill；将模型差异与 skill 版本差异分开比较。
- **原生能力基线**：无 skill 组也可使用相同的渲染、看图与修正工具，给予相同任务资料和总预算。只改变待测 skill 条件，保留基线组的同等修正机会。描摹路线仅参加有位图输入的可比任务；混合路线计入预处理、文字恢复、分组与服务等待。
- 默认选受改动影响的一题；维护通用路线前再补不同任务的案例。若同题已验证且规则未变，不重复跑。比较候选应保留原稿，评估者不代画；显示时统一坐标范围和比例并披露视口调整。

每次评测明确预算；到限保存已完成稿，记录 timed_out 和缺项。允许局部修正，但各候选拥有相同修正预算。输出 SVG、实际预览及一条结果记录，不默认 PPT 或长报告。

局部编辑题可在单模型流程中沿用它的建筑稿；跨模型比较编辑能力时，先固定同一份源 SVG 给所有候选，避免源稿差异影响结论。该题有意提供待修改素材，不混入无答案的从零构形测试。

## 怎么判断

先核对交付底线：SVG 结构、真实透明、可联动语义组、无科学性误导。结构用现有 `scripts/check_svg.py`；透明与轮廓需实际渲染。结构与画质分别记录结果。

### 科学保真与真实增益

出图前依据题目/参考确定少量关键验收条件，覆盖本题实际涉及的对象身份、空间/边界、连接/方向和数量/状态，区分必须保持与允许简化。验收依据采用题目、参考或独立资料。评估者依来源与实际渲染核对，未知项记未验。

关键科学错误单列并优先处理。先比较关键错误及达到相同质量所需的实际人工修正时间，再比较总耗时。跨类别、未见任务和三类输入分开报告；skill 收益依据同条件对照判断。保留全部对照结果，无显著收益时删减无效流程。

图像生成模型产出的输入另记来源；其内容可能与科学说明冲突。预先明确科学依据及冲突验收，不只测像素相似度。合成教学草图用于测试冲突处理，来源标为教学构造。发表表现按本次版面尺寸检查，并与科学内容结论分开。结论注明本次案例、类别与版面尺寸。

### 局部编辑的两个独立结果

- **目标修复**：先写清部件与可观察要求，例如“外露喙长度和喙根衔接与照片相符”，验收要求写成可观察的形态变化。对比相同视口下原图、修前、修后的目标区域，记录 pass/fail/unverified 及依据。
- **区域保护**：列出本次允许修改的最小部件；核对其余内容、父级transform、叠放顺序、defs与共享样式。可运行 `python scripts/check_edit_scope.py before.svg after.svg --allow head`；多个部件可重复 --allow。
- 两者均 pass 才接受；任一未验则整项未完成。没有改动也可能通过保护检查，因此脚本同时报告 target_changed，但始终将 target_verified 留空。退出码0仅表示源码范围检查通过。
- 该工具已包含 check_svg.py 的结构检查，并对源码作保守比较。浮点几何等价、共享引用、CSS 或合法重构产生告警时，按事先确定的修改范围核对依赖与实际渲染。
- 对比修前修后；退化或无有效改善时保留原稿。候选稿以实际改善和区域保护结果决定是否采用。

最小记录为 target_result / target_evidence / protected_result / protected_evidence / decision。无需每次另建JSON文件，可放进现有制作说明。

含字题另外核对实际文字、单位与上下标、对象对应、版面可读性；字体近似与内容识别分开记录。编辑题实际执行要求的动作，记录成功/失败/未验及错误联动的位置；若指定目标应用，保存重开后再确认。检查记录包含实际操作结果；新增题目初始状态为待执行。

视觉按以下维度记录 **达标 / 需局部修正 / 明显不符 / 未验**，每项附一个可指认位置或现象：

1. 轮廓与比例；
2. 识别特征、数量与连接；
3. 层叠、接合与支撑关系；
4. 细节/纹理自然度与目标风格；
5. 编辑联动。

不可见足趾等推定项单列，依据可用证据记录判断。尽量先隐藏模型标签看图，再揭示时间；条件不允许则注明评估非盲。结论引用上述维度的具体观察。

记录从发起到保存、代理完成与整次交付的时间边界，包含输入准备、读规则、思考、绘制、导出和验证；纯脚本运行时间另列。修正量分成模型自修轮数、评估者/用户实际修改分钟、剩余需修部位；尚未实际修正时写“未测”。token/费用不可得则写未知。

项目内保存一条 JSON/表格记录即可，字段：

```text
case_id, input_ref, input_seen, model_id, host, reasoning,
skill_snapshot_ref, route, supplied_aids, time_budget_seconds,
started_at, artifact_saved_at, model_finished_at, delivered_at,
self_revision_count, human_edit_minutes_or_null,
quality_by_dimension_with_evidence, structure, alpha, grouping,
status, remaining_defects, svg_ref, preview_ref, reviewer, blinded
```

skill_snapshot_ref 指实际保留的版本/文件快照，模型版本未知时明示。无需每次跑哈希；只保留可追溯版本和输入引用。隐私输入及其衍生图留在所属项目，未经确认不进入公共 skill 包或素材库。

## 从记录到选择

### 通用规则的迁移检查

更新通用构形规则时，保留触发问题的失败样本，并用不同类别及一个反例检查适用边界。单次修正记录为对应对象的局部结果；专项画法、素材模板和部件数量保留其适用范围。

| 待测约束 | 迁移情境 | 反例/失败信号 |
| --- | --- | --- |
| 关系与几何一致 | 生物附属结构、设备接口、流程箭头 | 接到最近对象、箭头改变含义、把遮挡当断开 |
| 保留应有边界 | 容器内部结构、开口、相邻独立对象 | 为连通填满间隙，或让所有曲线都平滑 |
| 编辑意图与绘制层次 | 前后穿插的部件、跨组共用结构 | 同组就认定归属正确，重组破坏叠放 |
| 允许必要的局部重构 | 位置错误但路径完整的对象 | 为保持原路径不变不断添加补线 |

按待验证的约束选择相关情境。优先用现有或新建的小型原创几何任务验证边界，保留不同于修订示例的未见任务。观察输出行为和实际渲染；文字情境检查记录为规则理解证据。真正评估通用收益仍需固定条件的跨类别出图对照，同时记录总耗时和修正量。

优先比较达到同一质量目标的路线，再看总耗时和修正量。若全都未达标，记录“均未达标”及各自缺陷。单例结果仅供相近任务参考；多种输入的重复证据充分后才能提升为暂定默认，并保留适用范围。

已有鸟图对照及局部修复实验发现：自估锚点未让目标喙形达标，而保护区域检查通过。这支持将两项验收分开，尚未证明新增辅助能提升画质。旧记录留在项目评测目录，不写进固定模型排行榜。按缺陷查找 [修复案例](repair-cases.md)，失败候选保留在失败案例中。
