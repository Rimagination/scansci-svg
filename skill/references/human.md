# 人类活动画法

证据：本类 5 个样本已观察（2026-09-07）：工厂（剪影）、网箱养鱼（示意组合）、萨摩亚外伸支架独木舟、拖拉机、皮卡；高层建筑见 [共同画法 B](drawing-grammar.md)。记录见 [证据](ian-study.md)。下列数值为本地绘图建议，按当前对象与版面调整。

## 三种完成度

| 模式 | 样本 | 路径预算 |
| --- | --- | --- |
| 剪影图标 | 工厂 | 4-10 条路径；单色剪影 + 反色镂空窗格/门 |
| 示意组合 | 网箱 | 边界符号 + 构件符号 + 少量写实小件点缀 |
| 写实载具/机械 | 拖拉机、皮卡 | 60-110 条路径；多面块着色 + 车轮同心圆 |

同一场景可混用：主体写实、远景剪影；但单件素材内不混。

## 观察到的共同规则

- 侧视车轮可用同心圆栈（胎/辋/毂）；斜视轮面按投影变成椭圆。轮子须接触共同地面平面，三维图中无需位于同一屏幕水平线。轮径依真实对象确定。
- 写实载具的分面：主色面 + 深色侧影面 + 玻璃深色块；皮卡 64 条路径里大半是分面与窗。
- 机械的识别优先级：拖拉机=大后轮+高排气管+驾驶舱；工厂=烟囱阵列+锯齿天际线；符号层先保这些。
- 网箱样本里 5 条写实小鱼占了全图大半路径（358 条）——写实质感是有意点缀的，边界本身只是虚线圆角矩形 + 两个黄色浮球。
- 船 = 对称细长梭形船体剖面 + 条带装饰色；外支架=舷外细长浮筒 + 2 根斜撑。

## 各模式构造

### 剪影图标（工厂为依据）
- 一条外剪影承载全部体量（厂房 + 烟囱/锯齿顶），烟囱高差与疏密是轮廓节奏。
- 透明镂空使用复合路径和 `fill-rule="evenodd"` 等真实扣空；填充背景色的矩形仅适用于有意的不透明背景。窗格保持行列对齐，门等功能性缺口同理。
- 悬浮感检查：剪影底部必须接地或带地面线。

### 示意组合（网箱为依据）
- 边界 = 虚线圆角矩形/椭圆，线宽克制，表达"范围"而非物体。
- 构件 = 最少可识别符号：浮球（小半圆）、锚线（细线）、投饵机（小方块）等。
- 点缀写实物（鱼群、海草）直接复用对应指南模板，缩到场景尺度的 5-15%，数量 3-8 个。
- 组合内每个对象保持独立 `<g>`，便于用户增删。

### 写实载具与机械（拖拉机、皮卡为依据）
- 步骤：接地线与轮位 → 车体侧面主平面 → 车顶/舱与玻璃 → 分面明暗 → 车灯、把手等小件。
- 简图玻璃可用深色或半透明块；需要透明质感时保留必要高光。样本的乘员可提炼为单色剪影，其他载具按当前用途选择完成度。
- 分面色 = 主色 + 同色相更深一档（侧面/下缘），高光面可提亮一档；不超过 3 档。
- 机械臂/犁具等附件：锥形闭合路径 + 铰接圆点；管路细于臂。

## 待验证的本地推演

- 人物活动（农夫、渔夫等相册条目）未学习；需要时按"头-躯干-四肢锥形段+单色剪影"推演并标注。
- 风机、光伏阵列、灌溉枢纽：平面阵列语法（重复构件）推演。风机已通过原创验证（2026-09-07）：塔筒锥形 + 轮毂圆 + 三叶片单形旋转 120°/240° 复用；光伏/灌溉仍未验证。
- 房屋（低层住宅、高脚屋）、教堂、剧场等相册条目未学习；沿用共同画法 B 的立面映射 + 识别构件（屋顶形、门位）推演。
- 渔具网具（渔网、蟹笼）的网眼纹理未学习。
