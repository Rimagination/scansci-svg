## 窗口错位：可复现的最小修正

- 输入：[修前 SVG](../assets/repair-window-before.svg)；结果：[修后 SVG](../assets/repair-window-after.svg)。此组为手工构造的教学对照。
- 先看[修前预览](../assets/repair-window-before.png)与[修后预览](../assets/repair-window-after.png)，需要理解路径时再读SVG。
- 要求：玻璃位于窗框内，四边留5个单位；墙体、屋顶和门不变。允许改 window 部件。
- 缺陷：glass 的 x=-45，使玻璃落在窗框左侧。修正为 x=5，保留 y=5、宽50、高40。窗框尺寸60×50，四边间距均为5。
- frame 与 glass 同在 window 组，移动 window 时共同变换。示例用于局部定位与联动，新图依当前尺寸设置间距。
- 验证：实际渲染前后图；计算四边间距；运行范围检查确认 window 以外完全不变。语义正确性由这条明确几何要求验证，无需模型自评。
- 来源：ScanSci 原创教学几何，无外部照片或第三方路径；未额外授予公共素材许可。

## 鸟类失败卡：喙根与足趾

**喙根混淆**：一次自估锚点修正将路径起点右移，喙尖和头部外轮廓几乎不变，外露喙仍偏长。源码范围检查通过，但目标失败。先区分可见嘴角/口缘与喙体边界，再对照照片检查修后外露长度和接合位置。

**分叉线足趾**：保留前后趾的空间关系、趾根、弯曲与爪尖；足式依对应物种确定。遮挡部分先标不确定，展示性补画另行说明。后续较完整的重绘仍须核对，未获确认前保持 candidate 状态。

上述私有照片与输出留在所属项目的评测目录，本 skill 记录失败现象及相关位置。自然主义喙/足的正确案例待确认，候选稿完成验证后再更新状态。

## 新案例如何加入

在用户授权的学习/绘图任务中，记录：缺陷标签、任务要求、before/after/实际预览引用、允许改动的部件、目标证据、保护证据、状态、来源/许可、未确认项。状态仅用 failed / candidate / verified；verified 注明具体验证范围，如“矩形间距”。

视觉素材以实际查看结果记录状态；复用他人素材前核对该素材的图像许可。参考库先按缺陷与部件组织，再附植物/动物/微生物/设施等原分类，避免每个物种创建长流程。

## 方法来源与本地改动

- [Vector-Bench](https://arxiv.org/abs/2607.19056)：借鉴“要求的修复”和“保护对象”分开评价。本地范围检查器自行实现，不复现其完整评分方法。
- [RefineSVG](https://github.com/liuxiaobo66/RefineSVG)：借鉴用可视草稿与修正对积累证据。本地采用按需范例提示，记录对应修正前后的实际效果。
- [Chat2SVG](https://github.com/kingnobro/Chat2SVG)：借鉴修正可能退化、需比较前后；未接入其扩散/分割/优化流水线。
- [Bioicons](https://github.com/duerrsimon/bioicons)：借鉴类别检索与逐素材来源记录；本轮未下载其素材或复制代码。
