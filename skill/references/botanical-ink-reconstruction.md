# 植物墨线图：先生图后重建

适用于精细植物墨线图及其原生 SVG 重建。墨线图强调纤细而明确的轮廓、随表面变化的排线、点描、自然转折和器官层次。用户使用“墨线图”时，文件说明、标题及投稿标签沿用此名称；普通黑白线稿保持原有入口。

## 输入与路线

- 已有满意的生成图或插画：查看原图和重点局部，直接重建；用户要求保留的构图、姿态和细节作为视觉基准。
- 从物种名称开始：先查看目标物种照片并阅读形态描述，再用可用的图像生成工具制作墨线参考。实际向工具传入已查看的风格参考文件，并说明其只约束笔法；物种照片与描述共同约束形态。工具调用须遵循当前宿主的图片引用方式。
- 用户要求 SVG 时，生图是中间步骤，继续完成重建与预览。生图工具不可用时说明实际限制，并按已授权范围使用已有参考或直接构形，不能声称完成了生图。
- “转为 SVG”可选忠实描摹；“重建”“按部件编辑”“精确制作”采用原生构形，复杂局部可辅助描摹并整理。生成图只提供视觉参考，科学结构仍需独立依据。

## 生成参考

在提示中写清物种、发育阶段、图件范围、形态证据支持的叶序与花果特征、连续连接、线宽层级、纹理方向和留白。采用已确认的无字母标注偏好；比例尺须有标定数据。默认不添加未要求的解剖局部或根系。

检查整体比例及器官身份后再进入重建：叶片与果实应凭外形和结构可区分；叶基、叶柄或叶鞘、花果梗与母轴接合明确。遮挡允许轮廓中断，独立局部允许分离。生成图出现错误时修正对应部位，避免把错误转成精细路径。

## 原生 SVG 重建

1. **锁定视觉基准。** 沿原图画幅记录茎轴走向、器官附着点、叶尖、弯折和花序边界。保持主要对象的相对位置和姿态，必要的形态纠错在交付时说明。
2. **共用连接点。** 叶基与叶柄/叶鞘、花果梗与母轴使用相同接口坐标。器官移动时更新所依附的结构；检查实际渲染中的连续性。草本的叶鞘应沿对应茎轴包接，不能按大致位置另放一个套筒。
3. **重画轮廓与叠放。** 用少量适当的贝塞尔曲线表达轮廓和真实弯折；前景器官遮住后方线条，白色器官内面可保留遮挡。对象轮廓不应因算法采样、舍入或平滑出现波浪、接缝或变形。
4. **按形态补细节。** 叶脉遵循脉序；刚毛从有依据的着生点发出；花果按各自结构描绘。点描与排线服从体积和转面，保留粗细、疏密和不规则变化。重复循环可生成局部细节，但不能让花序呈现规则梳齿、让全部叶片使用同一弧线，或以增加路径数代替观察。
5. **按编辑用途分组。** 全株、各茎、各叶及其叶脉/叶鞘、各花序及其小穗/刚毛保持明确归属和稳定 ID。相同样式的细节可在所属器官内合并为多段路径；跨器官合并会损失编辑能力。不要用嵌入位图充当原生重建结果。

## 精确程度怎样验收

同时看原图与 SVG 的同尺寸渲染，并放大一个细节密集区、一个器官接合区和一处曲线转折。具体核对：

- 外轮廓、长宽比、叶尖、弯曲方向和留白是否保留；
- 叶脉、刚毛和排线是否连续，是否出现黑块、残片、缺失或过度规整；
- 器官身份、着生和遮挡是否有依据；
- 整株及主要部件能否按约定选择、修改；必要时在副本上进行一次代表性编辑；
- 文件结构检查和实际渲染是否都通过。结构检查无法证明科学正确或精确还原。

“精确”须由上述对照支持。存在可见差异时继续修正，或具体标明尚未还原的部位；未经量化对照不报告相似度百分比。生成参考、重建结果与实际上传副本分别保留，以便追溯差异。

## 转换与上传的实际教训

狗尾草试验中，直接二值描摹丢失大量浅色刚毛和叶脉；保留灰阶的自动描摹产生约 20.8 MB 文件和大量碎片。原生重建降至约 760 KB，并按器官分组，但叶片曲线与花序排列仍偏规整。该例展示路线与编辑组织，尚不能作为精确还原或分类学定稿范本。

上传前读取服务端当前大小及节点限制。优先精简冗余采样、无效属性和同器官内重复样式；保留原始精度主稿。路径精度降低可能引入波浪和折线，不能只以体积合格决定发布。压缩后复查相同局部；无法同时满足细节与大小限制时说明具体差异，不默默降低质量。不要把某次平台限额写成绘图通用约束。
