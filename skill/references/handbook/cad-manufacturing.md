# SVG、CAD 与实体制作

资料核实：2026-09-12。目录：[DXF / DWG](#cad) · [切割与绘图机](#toolpaths) · [三维](#three-d) · [刺绣](#embroidery)。

本页把二维外观、工程几何与机器动作分别说明。文档路线执行时确认已安装软件的过滤器、单位和目标设备；项目现有制作脚本的范围见 [路径提取与实体制作](../fabrication-and-layers.md)。

<a id="cad"></a>
## SVG ↔ DXF / DWG

**SVG → DXF：**在 Inkscape 的“另存副本”中选择安装环境提供的 DXF R12 / R14 输出。先把所需轮廓选出，固定物理尺寸，再处理文字、基本形状和变换；具体曲线是否输出为样条或折线，由扩展及目标 CAD 支持决定。Inkscape 官方列出这两种 DXF 过滤器，部分格式需要附加程序。[Inkscape 格式导出](https://inkscape-manuals.readthedocs.io/en/latest/export-other-formats.html)

**DXF → SVG：**用于论文或网页展示时，ezdxf 的 drawing add-on 提供 `SVGBackend`，把选定 CAD 布局绘制为 SVG。布局系统会处理页坐标以及 SVG 向下的 y 轴；模型空间和纸张空间应按用户要展示的内容选择。它输出绘图结果，CAD 的约束、块属性和完整工程模型继续随 DXF 保存。[ezdxf Drawing / SVGBackend](https://ezdxf.readthedocs.io/en/stable/addons/drawing.html#svgbackend)

**涉及 DWG：**先在能正确打开源 DWG 的 CAD 软件中选出图层、布局或二维投影，再导出 DXF 或 PDF，沿相应路线转换。SVG 返回工程图时，先生成目标支持的几何，再在 CAD 中补尺寸、约束和图层。此处提供中间格式路线；实际 DWG 软件、版本与导出能力在任务时核实。

| 应保留的信息 | 常见变化 | 一次有效检查 |
| --- | --- | --- |
| 轮廓和坐标 | 贝塞尔曲线可能离散；SVG y 向下，CAD 坐标约定不同 | 对照三个不共线基准点及一条曲线 |
| 实际尺寸 | SVG 用户单位、毫米和 CAD 单位可能混用 | 在 CAD 测量一个已知长度，如 20 mm |
| 孔洞与边界 | 填色、蒙版、裁剪可能只留下部分轮廓 | 检查闭合、自交、内孔和重复边 |
| 文字与标注 | 字形路径失去文字编辑；视觉尺寸线失去尺寸关联 | 改一个尺寸，确认几何与标注是否关联 |

带描边的轮廓先确定用途：沿原路径走一刀采用中心线；要切出粗描边占据的面积，则把描边展开成闭合边界。两种转换得到的零件不同。

<a id="toolpaths"></a>
## SVG → 切割图 / 绘图机 / G-code

先确定所选路径、目标毫米宽度和加工方式。连续曲线的离散步长按设备精度与曲率决定；清理重叠切线、开放缺口和极小碎片，保留真实细部。

现有 `svg_workshop.mjs` 按 ID 提取、采样几何，`fabricate_svg.py` 输出 `cut.svg`、`plot.svg` 等制作副本，调用方法与范围集中在 [现有制作流程](../fabrication-and-layers.md)。这类文件适合进入对应 CAM 或绘图机软件。

**SVG → G-code** 还需要 CAM 和后处理器：选择设备、工具、材料、切深、进给、坐标原点与刀具补偿。颜色分组可作为操作分组线索，具体机床动作由工艺定义。当前 skill 未提供通用 G-code 生成器；用户提出加工需求时先确定这些条件，再核实该设备的官方导入与后处理流程。

**反向得到 SVG** 可用于检查轨迹投影，但轨迹里有空移、重复切削和补偿，需选定哪些运动作为图形。已有 CAD / 设计源文件可用时从源文件导出。数字几何验收测闭合、尺寸与重复边；实体制作再进行机器仿真与对应材料的小样验证。

<a id="three-d"></a>
## SVG → Blender 曲线 / STL；三维 → SVG

Blender 提供 SVG as Curves 导入：路径转为曲线，导入的平面位置和缩放需要检查。先在交换副本中把需要的基本形状或文字转路径，再根据目标设置填充、挤出或倒角；SVG 中的配色、裁剪与材质表现逐项处理。[Blender SVG 曲线导入](https://docs.blender.org/manual/en/5.3/files/import_export/svg_curve.html)

挤出需要新信息：厚度、孔洞、实体合并方式和最终尺寸。该操作能制作标牌、轮廓模型或分层教具；一张植物侧视图中的隐藏表面需要额外形态依据与建模。

项目已有 `fabricate_svg.py` 的 STL 路线限定为**单个无孔、无自交的闭合平面轮廓＋明确厚度**。单位约定用毫米；STL 文件本身不带长度单位，导入切片器时再次确认。数字验证覆盖网格闭合、体积及回读，实体效果需制作验证。多孔、多实体或真实曲面转入相应 CAD / 三维建模工具。[现有 STL 范围与参数](../fabrication-and-layers.md)

**三维 → SVG：**先选正投影、透视轮廓、剖面或可见线稿，再用源软件支持的矢量输出路线。最终 SVG 保存的是选定视图；把多视图与三维源文件一起保存，才能继续换视角。仅有渲染截图时按图片重建处理。

<a id="embroidery"></a>
## SVG → DST / PES 刺绣文件

刺绣需要选择走针、缎面或填充等针法，并确定针距、顺序、换色、底针和面料。普通填色路径提供图案边界，针迹规划另行完成。

现有脚本通过可选 `pyembroidery` 依赖输出简单单色走针 DST / PES 与针迹预览，设有针距和绣框尺寸参数。已有检查覆盖针迹范围、跳针和格式回读；复杂填充和多色生产稿转入专用制版流程，按实际面料检验。[走针导出与验证](../fabrication-and-layers.md)

**DST / PES → SVG** 适合导出针迹可视化：先读回针迹与颜色/跳针信息，再投影成线段或路径；原图完整填充区域和语义部件需要源设计或重新组织。按用户目的交付“针迹预览”或“可编辑图案”，二者保留的信息不同。
