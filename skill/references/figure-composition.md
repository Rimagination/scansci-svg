# 科研组图

用户要求组合素材、机制图、图形摘要、多面板图或拼成一张图时使用。先沿用任务给出的内容、对象与关系，选择适合表达的组织方式。

| 用途 | 组织方式 | 决定成败的检查 |
| --- | --- | --- |
| 对比组图 | 对照与处理、物种或阶段按行列排列 | 对应部件、视角、颜色含义和尺寸口径一致 |
| 机制图 / 图形摘要 | 对象放入空间区域，连接表达过程与方向 | 箭头的源、汇和含义有依据，跨边界关系清楚 |
| 总览与局部 | 总体图配细节面板，框线或引线定位 | 局部确实来自指定对象与区域，放大倍率有依据才标数值 |
| 实验流程 | 按已知步骤组织材料、仪器、操作与产物 | 步骤顺序与连接来自实验方案，操作标签可编辑 |

## 从素材到整图

从现有描述确定画面要传达的一句话、所需面板和关系；用户给了排布时沿用。简单组图直接构造，重复拼版才使用布局文件。缺少机制关系时先完成确定的对象与版面，只询问影响科学含义的缺项。

优先查看现有素材的实际形态与来源，选对象、阶段和视角匹配的图。调整描边、配色、光照和细节密度，使整图看起来属于同一套。对含义不同的对象保留识别特征。新对象按主 skill 构形；提供的图表保留原有数据、坐标和单位。

对象缩放保持纵横比。比较真实大小时使用有尺度依据的共同缩放；仅比较形态时可按版面归一化，并注明“示意，非等比例”。全株、局部和仪器的不同尺寸口径分别说明。先安排主体、留白与标签区，再绘制连接，避免用空隙大小暗示未经确认的时间或距离。

## 可持续编辑的组织

- 每个面板、对象实例、关系线和图例有稳定具名组。保留源对象内部的部件组；为每个实例的全部 ID 加唯一前缀，同时重写本地引用。重复放入同一素材时，各实例可独立修改。
- 关系线单独分组，记录它连接的对象或部件 ID；箭头样式与图例说明具体含义。移动对象后按实际连接部位更新端点，并复查遮挡与交叉。静态 SVG 的端点需要随编辑更新。
- 面板号、标题、标签和图例保持 `<text>`。面板共同的图例独立放置，局部标签随所属部件组织。面板缩小时重新核对文字和描边的可读性。
- 独立导出面板时带上其引用的渐变、标记与裁剪定义；整图保留每个实例自己的定义与编辑范围。

## 轻量拼版工具

已有自包含 SVG 需要重复拼版时，用 `scripts/compose_svg.py`。脚本接受本地布局 JSON，将各 SVG 等比例放入指定区域，隔离 ID 和本地引用，保留嵌套 SVG 及部件组。源图使用属性或内联样式；含 `<style>` 的文件先解析为元素上的样式，避免选择器跨面板影响。科学关系、样式协调与连接线由绘制者决定。

```json
{
  "width": 1000,
  "height": 500,
  "title": "形态对比（示意，非等比例）",
  "panels": [
    {"id": "rice", "file": "rice.svg", "x": 20, "y": 60, "width": 450, "height": 400},
    {"id": "wheat", "file": "wheat.svg", "x": 520, "y": 60, "width": 450, "height": 400}
  ],
  "labels": [
    {"id": "rice-title", "text": "A  水稻", "x": 20, "y": 35},
    {"id": "wheat-title", "text": "B  小麦", "x": 520, "y": 35}
  ]
}
```

```text
python <skill目录>/scripts/compose_svg.py layout.json figure.svg
```

素材路径相对布局文件解析；画布和面板尺寸使用同一坐标单位，标签字号默认 18。输出为新文件。工具保留各图的原始 viewBox，使用 `xMidYMid meet` 等比例居中；预留的标签区由布局决定。根 SVG 的内联样式若声明尺寸或位置，先将这些声明转成 SVG 属性，使拼版尺寸由布局控制；脚本遇到这类输入会给出定位信息。

## 验收与交付

需要重复生成论文组图时，保留布局 JSON、各面板源文件和生成命令；替换指定面板后用同一布局输出新版本。可在布局增加 `"width_mm": 180` 设定最终物理宽度，高度按画布比例计算，原 viewBox、面板坐标和部件 ID 保持一致。字号与线宽按最终物理尺寸验收，用户指定期刊时采用对应要求。

将共同的版面修改写回布局，内容修改写回对应源图。每轮只生成新的交付文件；需要比较两版时检查被替换面板之外的图形与标签保持一致。数据图使用用户提供或既有分析流程生成的文件，沿用数据、单位与图例含义。

需持续返修的标签显式填写 `id`，重排面板时沿用该 ID。省略时脚本按顺序生成 `figure-label-1` 等名称。单标签修改可用 `check_edit_scope.py before.svg after.svg --allow rice-title` 核对保护范围，再看实际预览确认标签位置和内容。

检查整图的阅读顺序、图例一致性、连接含义与实际端点；按最终尺寸看标签、关键细线和面板间距。结构检查确认合并后的 ID 与引用；在一个代表性实例上试改部件，确认其他实例保持原状。

默认交付一个组合 SVG 和整图预览。用户要求各面板独立文件或可编辑 PPTX 时再导出相应文件；PPTX 沿用现有导出与目标应用检查流程。素材的来源与简化说明随整图保留。
