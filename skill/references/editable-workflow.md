# 文字与部件编辑

用于含字参考图重建、转绘伪影清理、部件联动、共享实例修改，以及指定编辑器交付。简单无字对象直接绘制；只读当前任务需要的段落。

## 参考文字重建

- 将可读文字与它标识的对象或关系对应起来；保留数值、单位、希腊字母、上下标、换行和箭头方向等科学含义。记录可沿用任务说明或代码变量，只有复杂排版或多轮恢复才另存文字清单。
- 忠实复现时保留参考位置、旋转、对齐和层叠；用户允许重新布局时随对象调整。参考没有字体元数据时，选择视觉接近的替代字体，并记录字体替代。
- 疑字先看原图局部或已有说明；影响科学含义仍无法确认时询问。不得借转绘改写数值、单位或将估计字形当原文。清晰内容继续制作。
- 直接重绘无需先去字。确需去字再矢量化时，先保留原图及文字记录；处理后对照非文字结构，特别看文字附近的箭尾、刻度、细线和边界，修复处理引入的变化后再接受结果。
- 用 `<text>`/`<tspan>` 恢复普通文字，必要时明确上下标的字号和基线偏移；几何描摹得到的字形路径应由可编辑文字替换，避免重复字。只有用户要求转曲时才交转曲副本并保留可编辑源稿。
- 按最终版面看一次实际渲染，核对文字内容、缺字、上下标、遮挡、错绑对象和越界。XML 中存在 `<text>` 只能证明有文字节点。

## 转绘洁净度

- **先理解整图，再选择画法**：先识别主要区域中的对象，以及跨区域的连接、包含、流向和标注关系；对待绘对象确定主体、必要部件、前后叠放和编辑归属，再构造路径。例如建筑由墙面、屋顶、窗户组成，窗户内部颜色变化不改变其归属。对象判断融入现有构形与分组即可，无需额外清单、JSON 或等待用户批准拆解。
- **按对象选择表示**：规则形体使用基本几何，重复部件复用几何，连续轮廓用少量可控曲线，明确的体积明暗用连续填充或渐变。只有必须保留且直接构形确有困难的局部轮廓才使用描摹；限定到该对象，保留其他对象的直接构形。无法确认的结构保留不确定性，不从压缩色斑或抗锯齿像素推断新部件。
- **颜色服从部件**：每条主要轮廓或色面应能说明属于哪个对象、表达何种边界、材质、阴影或纹理。按完整对象组织这些色面，并核对部件成员及实际编辑行为。
- **文字与底图一起清理**：恢复可编辑文字时，清除对应的旧字轮廓、抗锯齿残边及去字产生的斑点；底色应与所属形状连续。平滑区域出现方块、色带或脏边时，直接替换该区域的底色几何并移除失效碎片，重接必要的箭头和边界，避免用不同色矩形盖住旧字后留下补丁。
- **按含义保护细节**：对照参考区分伪影与真实纹理、表面颗粒、分界虚线、箭头、刻度及数据点。按目标部件清理，保留有意义的数量、位置与方向；清理范围依据上述含义逐对象确定。
- **目检要作出判断**：整体预览确认构图与关系，再以原始像素尺寸或适当放大对照关键平滑区域、恢复文字附近和细线交界。每处可见异常都要判断属于参考内容、允许的简化或制作缺陷；确认的残影、接缝、光晕和断线先修正，再复查结果。
- **失败时切换表示方法**：简单对象出现无意义色面或碎片，立即停止对它调色区参数，重建完整对象并移除失效路径。若当前任务中的多个对象反复出现同类问题，检查它们共用的生成方法，修正该方法并处理受影响的对象。按已授权范围修复，保护正确对象；局部结果清晰且关系完整即可结束，不增加全图试参循环、固定路径阈值或新审查流程。

## 按部件执行修改

先从当前 SVG 与任务确定三件事：目标部件、随它变化的成员、保持不变的对象和关系。沿用原有分组；分组妨碍正确编辑时才局部重构。部件归属依对象结构与编辑意图确定。

| 修改意图 | 联动与保护要求 |
| --- | --- |
| 移动或旋转部件 | 核对轮廓、内部细节及附属标注；测量轴或公共图例按其用途独立保留。 |
| 改一个重复实例的颜色/形状 | 检查 `use`、共享定义与样式；优先实例属性覆盖，必要时复制最小依赖并使用唯一 ID，保护其余实例。 |
| 改标签 | 修改文字及其必要排版；保留所指对象、单位和未要求变更的内容，避免变长后遮住箭头或边界。 |
| 移动带连接的对象 | 根据任务保持连接含义、端点归属与方向；仅更新必要端点/路径，仍然交叉但不相连的对象保持分离。 |

依赖对象的必要改动属于该编辑的范围，例如移动节点后接回它的连接线；在修改前界定范围，不为消除检查报错而扩大范围。请求“其余全部不变”与必要联动冲突时，先指出冲突并确认取舍。

在副本中执行当前要求的实际操作，检查目标是否达到要求、联动成员是否完整、无关区域是否保持、层叠是否合理。新素材没有指定编辑动作时，仅在联动有疑问处做一次代表性操作并撤销或丢弃副本，不为每个小对象增加测试流程。

需要工具证据时复用已有脚本；以下示意 ID 须替换为当前文件的真实 ID：

```powershell
python skill/scripts/check_edit_units.py figure.svg --unit window=frame,glass
python skill/scripts/check_edit_scope.py before.svg after.svg --allow window
```

以上命令从维护项目根目录运行；已安装 skill 按其目录解析脚本路径。成员检查验证指定成员在组内，成员完整性与联动通过实际操作核对；范围检查比较源码，遇到共享引用、CSS 或合法重构时核对依赖与实际渲染。两个检查均已包含 SVG 结构检查，运行其中之一即可覆盖该项。

## 目标编辑器交付

仅在用户指定 Illustrator、Inkscape、PowerPoint 等目标应用时执行。用现有可靠工具处理，保留原始 SVG；依据目标应用实际支持情况生成兼容副本，将兼容性处理记录到对应应用。

在独立副本或测试文档中导入，试选一个任务相关部件并做指定操作；有文字时实际改一处，随后保存并重开，核对文字、部件联动、层叠和透明效果。检查用改动应撤销，交付文件保持用户要求。若用户授权写入已有文档，保留其中已有内容并另存结果，避免覆盖原件。

只完成导出时记“已导出、目标应用编辑未验证”；完成实际操作才报告所测应用与行为。可编辑 SVG、目标应用原生对象和科学内容正确分别陈述。
