# 鸟类照片 → 自然主义透明 SVG

用于照片个体的矢量重绘。目标是自然比例、可识别羽色和可编辑结构。照片支配几何与斑纹；示范插画只提供用色、明暗、边缘和细节密度。物种特征依当前对象确定。手写 Bézier 路径可直接交付；自动描摹适合作轮廓参考，最终部件树按对象及其结构重建。

涉及具体鸟种或识别判断时，先按 [在线形态核实](morphology-evidence.md) 阅读专业物种条目，把喙形、头部/翼部羽斑、翼尾关系及必要的足式对应到下面的识别约束卡。按资料实际涵盖的性别、年龄、季节羽或亚种使用特征；照片未能确认的类型保持未定。文字物种任务也用该核实方法，再按指定姿态构形。

## 使用 AI 生成参考时

用户选择“先生成参考，再绘制 SVG”时，使用 imagegen。若目的在于减少对权利未明照片的依赖，采用文字物种描述，不传入原照片，也不要求复刻其独特姿态、背景或构图。按新生成图重新建立关键点与路径；已有衍生稿继续保留其原始来源记录。

生成图只提供构形参考。物种名称由任务指定，识别性羽斑与足式仍用可靠鸟类资料核对；修正生成图中的多趾、过长腿、异常羽区，清除残留背景。独立展示足姿沿用下方规则。记录生成工具、实际可知的模型、完整提示词、是否传入图像以及人工修正；模型版本未知时写未知。输出标注为生成参考及其矢量重绘；公开发布时核对适用许可与授权。

## 识别约束卡

绘制前做一份简短记录，复用到输出说明，不强制单独文档：

- **候选名称与依据**：优先使用多个可见特征的组合。只有照片时称“与……特征吻合”；地点、季节、声音和体长使用用户资料或图像元数据。地点和时间只有会改变候选判断时才询问。
- **必须保留**：头冠、眉纹/眼线/眼圈、颊斑、喉斑、翼斑/翼带、胸腹纹、尾形，以及喙与头身比例。列出该照片真正可见且有辨识力的项目。
- **待定项**：性别、年龄、亚种、不可见羽区。定龄或定性需要多项相符的诊断特征。无法确认时保留照片外观，标注未定，不补典型成鸟特征。
- **证据分开**：照片中看到的事实、权威资料支持的物种特征、为可读性做的艺术简化。物种归属与精细分型分开给置信判断；不使用虚构百分比。

若用户名称与可见诊断特征冲突，指出具体冲突，继续提供中性命名的照片忠实稿；保留照片的可见斑纹。确需变换物种时，应明确属于另一个构图任务。

## 鸟类知识如何约束画法

下表采用常用形态与羽区名称；定种时选择目标鸟类适用的诊断特征。

| 观察部位 | 转为几何约束 | 常见误导 |
| --- | --- | --- |
| 喙与头 | 标记喙尖、上下喙基、眼心与头冠顶点；保留长宽、弯曲及方向 | 所有鸟套三角喙；把细长喙缩成雀形喙 |
| 头部斑纹 | 眼圈、眉纹、眼线、颊斑、喉斑各自成形，边界服从照片 | 把白颊当白眼圈；把反光画成固定白斑 |
| 折叠翼 | 先定翼尖及覆羽覆盖关系，再画可见飞羽的方向和边缘 | 飞羽横穿胸腹；为对称而补出远侧翅膀 |
| 翼带与背纹 | 将可见浅色羽端连接成正确位置、宽度的带，保留深浅间隔 | 用随机碎白点取代翼带；擅自增加条数 |
| 尾 | 标记尾基、尾尖、叉口；尾羽位于身体/翼的正确后层 | 全部画成展开扇尾；把翅尖误认为尾尖 |
| 足与栖姿 | 记录可见跗跖、趾爪、抓握点及遮挡，保持与支撑物的接触方向 | 把站地足套到栖枝鸟；补出照片中看不见的脚趾 |

细节数服从可见投影和用途；解剖计数与示意数量分别记录，足趾排列依目标物种确定。虹彩、阴影与白平衡会改变颜色，辨识优先依靠位置、轮廓和对比关系。

## 从照片构形

以下是绘图优先级，可在直接写路径时完成；无需把每项变成单独文件或工具步骤。发生比例失真时，按 [跨模型执行卡](cross-model.md) 只补问题部位的锚点。

1. **把握空间关系**：观察喙尖、喙基、眼心、头顶、背部转折、肩部、翼尖、胸腹最低点、尾基/尾尖、可见腿的出羽点和抓握点。直接构形可用内部观察；需显式测量时统一采用照片坐标或归一化坐标，记录方向；不先套椭圆鸟模板。
2. **看剪影**：用少量曲线建立头颈、胸腹、背翼与尾的连续轮廓。先核对胖瘦、头身比、体轴倾角和翼尾长短，再添加花纹；姿态与物种特征分别核对。
3. **分语义层**：整鸟一个具名组，下设 `tail`、`body`、`wing`、`head`、两只可见足；头内有喙、眼、冠、颊斑和喉斑，翼内按可见羽区组织。通常尾与远足靠后、近翼靠前，具体顺序按照片遮挡。每片羽的明暗与边缘跟随该羽片或羽区，不跨组拆色。
4. **设大色区与缓慢明暗变化**：优先无外描边或极弱描边。渐变只塑造体积，避免大面积多边形亮面切碎胸腹。将关键黑白斑保留为清楚但自然的边界。
5. **补局部羽缘**：羽片顺生长方向，根部藏在覆羽之下。头颊用短而疏的羽缘，飞羽用长而窄的面片，胸腹用克制的层叠明暗。羽缘的方向、疏密和尺度随羽区变化，细节保留到目标版面可辨的层级。

## 独立展示与姿态适配

透明背景指实际 alpha/无背景形状；是否改变姿态取决于用途，不由“透明”一词单独决定。

- **单鸟独立展示、无支撑物素材**：对于原本栖枝/站立的鸟，允许小幅调整腿足，让趾爪舒展、轻弯，双足形成合理的支撑关系。按物种的足式和透视处理，落脚高度可接近，不强求机械对称。保持头身比例、表情、翼尾和诊断羽斑稳定；去枝后将抓握足姿调整为适合当前展示的舒展足姿。
- **忠实照片、保留原姿态、以后放回栖木**：保留照片可见抓握形态与遮挡，不为了独立好看改成站地足。若保留枝条，将其放在整鸟组外，便于单独编辑。
- **飞行、悬停、游泳等行为展示**：保留该行为的身体、翅尾和足姿关系，不统一转换成站姿。单足站立也不自动补一条腿。
- **只说“透明背景”且未明确用途**：先保留主体姿态去背景；只有用途差异会实质影响结果时再简短询问，小幅调整依用途直接完成。

姿态修改遵循“最小部件变更”：只改必要的腿足或接合处，其余组保留；改稿另存，保留照片姿态版。检查出羽点、腿长、关节方向、趾爪及重心支撑关系，避免脚离体、腿被拉长或尾巴意外穿地。用一句话说明足姿的展示性调整，交付当前用途对应的姿势。

具体对照见 [麻雀与欧亚鸲画法参考](bird-examples.md)：先看相应 PNG，确需学习分组/曲线时再定位 SVG 的相关组。

## 质量检查与不确定性

- 以照片逐项复核关键点与识别约束卡。
- 实际渲染大图及使用尺寸缩略图，查看浅底/深底下的羽缘、喙尖、趾爪；原始 SVG 不加底色。
- 验证 SVG 可解析、无嵌入位图/外链/脚本，ID 唯一、整鸟组与部件组存在。对照照片核对各羽区的形态、位置与遮挡。
- 输出 SVG 和轻量预览，简述保留特征、推定物种与未定项。有专家审定记录时附上实际意见。
- 用户提供图片用于本次私有转绘。拟公开分发衍生图时，核对原照片的再分发授权，并沿用该资产适用的许可。

## 已核实示例：树麻雀形态

2026-09-07 查阅下列资料。树麻雀 *Passer montanus* 的可用组合特征为栗色头冠、白颊中的黑斑、黑喉斑及短粗锥形喙；背部褐色深纹、腹面灰白。与雄性家麻雀比较时，栗色头冠和颊部黑斑有区分价值。雌雄外形近似。用户给定例图支持树麻雀候选；亚种、年龄与性别保持未定。

遇到其他物种，按同样方法核实对应的识别点。

- [Cornell Lab — Eurasian Tree Sparrow identification](https://www.allaboutbirds.org/guide/Eurasian_Tree_Sparrow/id)：候选种的体型、羽色与图例。
- [Audubon — Eurasian Tree Sparrow](https://www.audubon.org/field-guide/bird/eurasian-tree-sparrow)：与家麻雀的区别及雌雄近似。
- [Cornell Lab — Field Marks](https://www.allaboutbirds.org/news/bird-id-skills-field-marks/)：头部、翼部识别点与羽区名称。
- [Cornell Lab — Four Keys to Bird Identification](https://www.allaboutbirds.org/news/building-skills-the-4-keys-to-bird-identification/)：体形、色彩格局、行为及生境应结合考虑。只用用户确实提供的证据。
