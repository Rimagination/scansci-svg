# 农林渔业、人类活动与信息表达 SVG 类别

使用 [设施画法](human.md) 构建平面与重复构件，使用 [过程画法](processes.md) 组织方向与关系，生物个体转到 [生命类别](catalog-life.md)。每行给出完整对象及其编辑单元；IAN 编号对应 [来源相册](ian-albums.md)，`—` 为独立扩展。

专业入口：[FAO 植物生产与保护](https://www.fao.org/plant-production-protection/en)（2026-09-08 核对）提供作物生产、种子、植保与机械化资料入口。具体设施采用项目图纸或对应型号说明；人物动作依据任务和可见姿态，信息系统依据用户提供的架构及接口关系。
