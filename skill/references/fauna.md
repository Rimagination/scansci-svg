# 动物画法

证据：本类 5 个样本已观察（2026-09-07）：generic fish、灰狐、帝王蝶、岩蟹、大蓝鹭；其中 generic fish 的路径做了逐条阅读，其余为元素计数 + 渲染核对。记录见 [证据](ian-study.md)。下列数值为本地绘图建议，按当前对象与版面调整。

具体动物先按 [对象特征与结构核实](morphology-evidence.md) 查询适用的动物志、专业条目或原始描述，确定体节、附肢、鳍位、口器及诊断纹样；核对性别、幼成体和行为姿态。真实部件总数与照片中可见数量分开，下方样本的比例、对称布局和细节密度只作构形参考。鸟类照片另读 [鸟类规则](bird-photo.md)。

## 形态家族与样本依据

| 家族 | 样本 | 核心观察 |
| --- | --- | --- |
| 流线体 | generic fish | 全身一条闭合轮廓（背鳍棘、叉形尾、腹鳍都并入外轮廓）+ 白色眼圈/鳃弧覆盖，共 3 条路径 |
| 四足体 | 灰狐 | 侧面站姿；躯干由数个大渐变面块叠合，无外描边；深色尾梢、耳、口鼻为识别点 |
| 羽翼体（飞） | 大蓝鹭 | 翼=多层羽片 planes（渐变蓝灰），覆羽层叠飞羽；S 颈 + 平直长喙 + 拖后的腿 |
| 对称膜翅 | 帝王蝶 | 左右镜像；橙色翅室被粗黑翅脉分割，黑缘带白点列；躯体极小；133 条路径 |
| 壳体+关节足 | 岩蟹 | 宽圆甲壳带斑纹；8 条分节折角步足 + 2 只带缺口螯；足为锥形闭合路径 |

## 观察到的共同规则

- 眼睛是小型圆形重音，绝不放大；剪影风格里眼睛用反色圆，写实风格用黑圆 + 高光。
- 两种完成度：剪影加少量反色细节，或多层渐变面块。优先沿用已选风格；未指定时采用清晰的科研示意完成度，无需为简单单件反复询问。
- 颜色克制：一个主色 + 一个对比色（鱼），或 2-4 个明暗邻近色（狐灰白、蟹灰白、鹭蓝灰、蝶橙黑）。
- 关节动物的肢体 = 分段锥形闭合路径，弯折处内侧收窄。

## 各家族构造

### 流线体（鱼为依据）
- 一条闭合轮廓承载全身：体侧线 → 尾叉凹口 → 背鳍棘/鳍膜缺口 → 腹鳍 → 回到吻部。
- 鳍的锯齿数 4-8 个即可有节奏；尾叉深度约为体长 1/8-1/6。
- 眼圈、鳃弧、腹部反光条可作少量细节。物种差异先调整吻形、鳍位、尾形；内部斑纹等若属于识别特征则保留。
- 特化体型的推演（标记未验证）：鳐=横宽菱形 + 细长尾；鲨=更大吻部 + 歪形尾。

### 四足体（灰狐为依据）
- 部件树：头（吻、耳、眼）→ 颈 → 躯干 2-3 个叠合面块 → 四肢（每条 2-3 段）→ 尾。
- 躯干面块沿背脊线到胸腹渐变，上亮下暗；腿上端并入躯干轮廓。
- 识别优先级：耳形 > 吻长 > 体比例 > 尾姿；尾梢深色块是常见重音。
- 大猫/鹿/海兽等按同一部件树改比例与耳吻细节；蹄类腿部收细属推演，标记未验证。

### 羽翼体（鹭为依据）
- 飞姿：翼展为构图的 60-75%；翼 = 3-6 层羽片，后层大而暗、前层小而亮；羽端整齐或略散。
- 颈按物种走 S 或直伸；喙直而尖（长度是涉禽识别点）；飞行中腿并拢拖后，细于翼。
- 站姿：原创验证已通过（企鹅测试，2026-09-07）：椭圆躯干 + 颈部短曲线 + 两蹼足接地，无 IAN 站姿样本核对，样本层面仍未验证。喙与颈长定种。

### 对称膜翅（蝶为依据）
- 只画一侧前/后翅，镜像复制；翅室 5-10 个橙/主色块，黑翅脉粗且随翅缘收拢。
- 黑缘带内缀白点列（点=小圆，间距渐变）；躯体 = 头胸腹三节 + 弯曲触角 + 细足 2-3 对可见。
- 蜻蜓类平展四翅按同一镜像语法（推演）；甲虫鞘翅对合线是识别点（推演）。

### 壳体+关节足（蟹为依据）
- 甲壳 = 横宽圆轮廓，宽:高约 2:1；表面可加少量斑纹路径。
- 步足 4 对（可见 3-4 对），每条 = 长节-腕-掌 2-3 段，向两侧下放射；螯足大 1.5-2 倍并带钳口缺口。
- 虾/龙虾按同语法拉长腹部并叠环节（Album 有样本未学习，属推演）。

- 鸟类巢/蛋、兽类幼体比例：未学习。
