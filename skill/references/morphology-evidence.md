# 对象特征与结构核实

用于具体生物、组织、分子、仪器与场地的绘制、鉴别和结构修正。目标是让少量有依据的特征落实到成稿；检索和记录随当前任务进行，不预建全对象资料库。

缺少适用的生物图像依据时，使用 [影像数据库入口](species-image-reference.md)：脚本可取 iNaturalist / GBIF 的分类与影像记录，查看实际图片后按本页方法核对特征并绘制。已有素材的证据不足以覆盖新姿态、阶段或器官时也按此补查。

## 图像与描述共同约束生物绘图

鸟类、昆虫与植物的新绘和形态修改，构形前同时具备实际图像观察与相关形态/解剖描述的依据。两类依据可来自同一专业条目；已有充分且适用的记录直接复用，不要求固定来源数量。纯配色、文字或整组平移无需重新检索。

- **选取相容材料**：对齐分类单元、阶段、性别及需要的视角。实际查看有记录的照片、标本或专业图版，再阅读对应描述；数据库标签、检索摘要和生成插画不能单独完成核对。图像说明姿态与可见结构，描述帮助解释器官及其连接；涉及内部结构时选相应解剖资料。
- **通用示意也有依据**：选取与任务相容的代表种或明确类群，记录哪些特征被概括。外形轮廓相似的器官分别查证，不能把叶形路径直接当作果实，或把翅、尾、足等附属结构随意替换。用户明确要求幻想生物时按创作目标处理。
- **按器官落实**：在现有说明中简记“部位 → 图像观察 → 描述约束 → 图中处理”，只写影响当前绘图的项目。选定依据后再画数量、相对比例、接口与遮挡；关键部位缺项先定向补查。无法补齐时明确指出受影响部位并请求所需材料，尚未核实的部分不标为科学验收通过。

| 类别 | 图像与描述需共同核对的部位（按当前范围选择） |
| --- | --- |
| 植物 | 主轴与分枝、节位和叶序；单叶/复叶及小叶柄；叶与花果的器官轮廓、纹理和着生；花部数量、花序、果实类型与阶段；任务涉及的根或地下器官 |
| 鸟类 | 喙与头身比例、翼尾边界及羽区覆盖；腿足出羽位置、关节方向、趾爪排列和支撑接触；当前性别、年龄、季节羽的诊断特征 |
| 昆虫 | 头胸腹边界；触角、足和翅的所属体段与着生；足段和关节；前后翅/鞘翅的对应和遮挡；口器、翅脉或其他任务所需的诊断结构，按生命阶段核对 |

### 构形与成稿的两项重点

- **器官可辨认**：先靠有依据的轮廓、结构和纹理表达“是什么”，再用标签补充名称。叶脉、果实缝合线、羽轴、翅脉和排线各有含义；去掉标签后仍应能辨认本图需要区分的器官，无法凭外观区分时用有依据的局部或视图说明。不能为突出差异而编造种子鼓包、毛被或脉纹。
- **连接可追踪**：沿每个器官回查到其所属轴、体段或接合部。已确认的接合使用同一几何位置；用曲线构形时从所属曲线求着生点，避免独立猜两个端点。归属先由形态确定，不把器官自动吸附到最近的任意线条。独立细节图、真实断裂和遮挡分别表达，正常主图不得出现无依据的悬空器官。

交付前在实际渲染的整图和关键部位放大图中核对上述两项，并看最终使用尺寸。SVG 分组、坐标或连接断言只能辅助检查；还要查看白色填充、遮挡顺序和缩放是否造成可见断口或器官混淆。修正共享画法后复查其全部调用对象。交付简述实际用过的图像与描述来源、保留的诊断特征、概括范围与未确认项；没有实绘对照或专家意见时不声称质量增益或专家验收。

## 何时查、查到哪里停

- 具体对象或识别性形态任务先复用当前任务或项目已有、可追溯且与对象及状态匹配的资料；缺项才在线核实。优先读已知记录，避免为找缓存遍历整个工作区。陌生名称、相近种/型号混淆、照片与描述冲突时定向补查。
- 仅凭照片且名称不明时，按可见特征组合找候选；未能排除近似种时保留中性名称或候选，不为完成绘图强行定种。只画通用植物/鸟形时保留通用层级。
- 先解决会影响本图的轮廓、部件、数量、接口、层次和诊断特征。一个明确适用的专业条目足以支持无争议特征；资料冲突、近似对象或关键特征缺失时再查独立来源。关键信息充分即可绘制，不按固定站点数收集资料。
- 首轮围绕少量关键特征合并检索，优先一个适用的专业条目；并发读取互不依赖的必要来源。检索围绕影响构形的特征组织，机制来源仅按过程表达的需要补查。
- 网页遇到验证页、超时或拒绝访问时，普通示意图先换一个可访问的专业来源；替代仍失败就结束这一支检索，不连续尝试同篇论文的多种镜像。可省略非必要且无证据的细节，继续绘制已有支持的部分；缺项决定对象身份、核心结构或用户明确要求时，保留问题并定向解决，在需求中保留该项，补齐依据后绘制。搜索结果用于定位来源，核实记录引用实际读过的正文。

## 来源与适用范围

生物优先用学名并核对中文名、异名及分类单元；设备用厂家和完整型号，小分子用明确化学结构或化合物标识，大分子三维结构用结构编号，场地用地点及调查编号。对象身份匹配与特征证据分别确认。下表按当前对象选一行，实际引用须落到读过的条目、描述、图版或论文，引用链接定位到该条目或正文。

| 对象 | 优先来源 | 使用边界 |
| --- | --- | --- |
| 植物 | [植物智](https://www.iplant.cn/)中的植物志与物种资料；[Kew POWO](https://powo.science.kew.org/)中的名称、描述及所引原始文献 | 查看描述原出处、分类范围及阶段；叶序、花果和根型引用有相应形态描述的资料。 |
| 鸟类 | Cornell Lab 的 [All About Birds](https://www.allaboutbirds.org/guide/)物种识别条目；研究机构、博物馆物种资料或相关形态研究 | 核对覆盖地域、近似种以及雌雄、成幼和季节羽差异；照片个体的亚种或年龄依对应诊断特征确认。 |
| 其他动物 | 动物志、博物馆资料和分类描述论文；[Animal Diversity Web](https://animaldiversity.org/)可作带参考文献的检索入口 | 按物种、性别、发育阶段与姿态核对体节、附肢、口器、触角、鳍位及纹样；必要时追溯原始描述。 |
| 真菌、藻类及微生物 | 分类专著、原始物种描述、菌种保藏机构；细菌和古菌可查 [BacDive](https://bacdive.dsmz.de/)及其所引文献 | 核对菌株/品系、生活史、培养和成像条件；细胞、菌落与群落形态分别处理。形态判断引用对应菌株的形态描述或图像。 |
| 细胞、组织与器官 | 专业解剖/组织学图谱、研究机构图像库及原始研究 | 核对物种、组织部位、健康/实验状态、切面方向、染色与成像方式；典型布局用于概括示意，样本再现依据该样本的成像资料。 |
| 化学小分子 | 用户给定的明确结构、权威化合物条目或结构论文 | 核对原子连接、键级、电荷、立体化学及任务所需状态；已有完整结构时直接使用，不为二维结构式强求三维编号。 |
| 大分子与病毒结构 | [RCSB PDB](https://www.rcsb.org/)条目、结构论文及装配说明 | 记录结构编号、实验/预测来源、构象及生物学装配体；核对亚基、对称性和缺失区域，避免将晶体不对称单元当完整功能复合体。 |
| 仪器与工程部件 | 厂家对应型号的说明书、尺寸图、装配图与接口文档 | 核对版本、选配件、单位及视图；照片显示实际配置，其他型号的接口和内部结构不自动移植。 |
| 土壤、岩石与地貌 | 实地调查/钻孔记录、地质调查机构资料；[USDA 土壤调查手册](https://www.nrcs.usda.gov/resources/guides-and-instructions/soil-survey-manual)可作剖面描述方法入口 | 实地再现依对应地点、深度、日期与原始数据；概念剖面可参考通用资料；该地点的层厚与水位使用现场记录。 |
| 形态图像 | 专业条目配图、有记录信息的标本或实拍照片 | 看实际图像与图注；标本压制、拍摄角度和遮挡会改变外观。物种特征引用可追溯的专业描述或标本图像。 |

联网使用当前环境可用的搜索与网页工具；先读描述，再查看确有帮助的局部图像，不默认批量下载。图片观察与图片复用分别处理；打包或公开分发外部图像前核对并取得相应授权。

## 特征怎样进入图形

在现有制作说明中保留少量条目即可：**特征 → 适用条件 → 来源与查阅日期 → 本图对应部位/处理**。仅记录影响构形的特征，沿用现有制作说明。

- **植物**：按任务选择生活型、分枝/节位、叶序、单叶/复叶、叶基/叶柄、叶缘/叶脉、花序/果实和根型；核对营养与生殖阶段、幼成株及品种差异。花果不可见或非本图所需时不额外补画。
- **鸟类**：按任务选择喙形与头身比例、冠/眉/眼/颊/喉斑、翼带、翼尾轮廓和足式；对齐性别、年龄、季节羽和行为姿态。资料描述的全部羽区不必在单一投影中可见。
- **其他动物与微生物**：将有依据的体节、附肢数、着生位置、排列和分枝转为部件及其关系；真实总数与当前投影可见数分开。分别核对单个细胞、群体排列、菌落形态与染色颜色；鞭毛、芽孢或生殖结构依对应对象的资料确定。
- **组织与分子**：组织按切面表达内外层次与腔隙；小分子保留连接、键级、电荷与立体化学，用已有化学绘图能力表达。大分子按装配状态表达亚基关系，有结构坐标时优先用已有工具读取与投影。明确缺失或未解析部位，预测结构与实验结构分别标明；概括团块标为功能示意，精确分子轮廓按结构坐标绘制。
- **仪器与剖面**：把尺寸、接口、支撑、层位和边界对应到几何。缺少内部/地下资料时保留外观或概念层级；当前设备配置使用对应型号资料，现场再现使用该地点的实测记录。
- **照片忠实稿**：照片决定该个体的姿态、可见比例和斑纹，专业资料帮助解释及鉴别。发生冲突时检查名称、阶段、视角和光照；不默默把照片改成典型成体或拼接其他个体的特征。
- **文字/生成图任务**：已核实形态约束主轮廓与部件关系，生成图仅供构图和风格。隐藏结构只有任务需要且有依据时才示意补绘，并说明补绘性质。
- 文献中的尺寸范围、模式图比例与照片投影分开使用；精确比例尺与个体尺寸使用对应标定或实测数据。

## 结构证据与机制证据

结构资料用于核对“有哪些部件、在哪里、怎样组成”。表达因果、调控、反应或输运前，另核对任务明确给出的关系或适用的实验/机制文献；作用方向与效果依相应关系说明或机制证据确定。任务指定的教学假设可按要求示意并标明；未获支持的关系保持未定，不为填满画面新增箭头。详见 [过程画法](processes.md)。

## 成稿核对与记录复用

看实际渲染，逐项对照本题选取的特征，指出对应的轮廓、着生部位、接口或层次；同时核对照片中的姿态与遮挡。发现特征与成稿不一致时修正对应部位。交付简述对象及状态标识、保留的关键特征、直接来源链接、实质简化/补绘与未确认项。

任务资料存所属项目的研究/输出位置，可复用同对象且条件匹配的记录；名称或来源有更新疑问、出现冲突或状态/版本不同再查。将特征沉淀为公共规则时保留对象与适用边界，跨类别适用性和画质增益通过相应对照验证后记录。
