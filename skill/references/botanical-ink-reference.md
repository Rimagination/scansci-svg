## 如何用于新 SVG

实际查看总览后，按任务选择相关原图放大观察；不要仅凭文件名声称已参考。记录本次采用的画法即可，无需每次加载全部九张。

- 轮廓轻而确定，主轮廓、主脉与细脉有层次；避免所有边缘同粗或机械重复。
- 排线沿表面转折与器官长轴变化；点描集中于需要交代转面、凹陷或表面质地的位置，保留大块白面。点、毛被和腺体的形态含义依证据区分，勿把装饰点误作真实结构。
- 叶片弯曲、翻折与重叠通过轮廓转向和遮挡表达。主图中叶基、叶柄、枝条、花梗与果梗的着生连续可辨；分离展示仅用于明确独立的局部。
- 花、果、叶使用各自有依据的轮廓和内部结构；先核对器官身份，再添加纹理。不可把叶脉模式套到果实上。
- SVG 用具名器官组保留原生路径，细脉、毛被、点描与排线归属对应器官；总览本身由位图排版形成，不属于可编辑植物 SVG 示例。
- 同类器官保留合理的姿态差异；本组参考中反复出现的叶缘、花序、根型与解剖结构不自动迁移到新物种。全株或枝条范围和独立局部数量按当前请求确定。

成稿对照选定原图检查线宽层级、点描疏密、排线方向、负空间与整体姿态，再对照目标物种图像和描述核对结构。总览缩放会损失细节，不用总览推断细脉、毛被、计数和尺度；这些原图未给出可用于新图的标定尺度。

## 来源与随包范围

九图由用户于 2026-09-15 在当前项目提供，原始附件文件名见同目录 `sources.json`。未提供可核实的作者、书目、页码、物种名称及再分发许可，当前只作为用户授权保存的本地风格参考；不据图猜定物种或宣称为某本植物志的正式图版。本项目的默认 ScanSci 署名与 CC-BY-4.0 投稿偏好不覆盖这些参考原图。

`botanical-ink/` 被项目 Git 忽略；本地安装同步会复制该目录。公开分发或打包上传时须排除此目录，取得适用的再分发许可后再调整。缺少本地参考包的安装仍可按 [植物分类学黑白线稿](botanical-line-art.md) 和当前用户材料绘制，不能声称已查看缺失图片。

参考板提供可重复查看的风格依据；输出质量提升须通过实际新图与对照验证。
