# 生物绘图：影像检索到 SVG

用户要求画植物、鸟类、昆虫或其他物种，当前任务缺少适用图像依据时启用。物种名、阶段和姿态已经明确就直接查；已有素材但需要新姿态、器官或阶段时同样补齐缺项。通用示意先选一个与需求相容的参考类群，脚本仅接受物种查询时使用该类群的明确代表种查图，并在记录中说明代表范围。单纯改色和已有充分依据的源稿复用原记录。图像与描述共同使用，见 [形态依据](morphology-evidence.md#图像与描述共同约束生物绘图)。

## 可直接调用的影像入口

`scripts/species_reference.py` 使用 Python 标准库访问公开只读 API，当前两个入口无需账户或密钥。输出少量带来源的图片候选，不下载整库：

```text
python <skill目录>/scripts/species_reference.py "Upupa epops" <任务目录>/hoopoe --limit 6
python <skill目录>/scripts/species_reference.py "Aquilegia vulgaris" <任务目录>/columbine --provider gbif --limit 6
```

默认 iNaturalist，接受能明确匹配的学名或常用名；中文名含糊时先核对学名。GBIF 入口使用已确认学名。首次生成 `references.json` 和 `preview.html`；同请求同目录再次运行复用记录，更新时明确用 `--refresh`。另一物种或另一来源用独立目录。参考页需联网加载远程图片。

| 来源 | 实际处理 | 选图时判断 |
| --- | --- | --- |
| [iNaturalist API](https://api.inaturalist.org/v1/docs/) | 精确匹配活动 species；取 research-grade 观测，按 votes 排序；校验观测为该种或其下级分类单元，保存每张照片署名、许可及观测链接 | 社区鉴定与票数用于筛选候选；逐张看清晰度、遮挡、姿态与个体状态，花园个体注意品种/杂交可能 |
| [GBIF Species](https://techdocs.gbif.org/en/openapi/v1/species) / [Occurrence](https://techdocs.gbif.org/en/openapi/v1/occurrence) | 精确到 species，异名取 acceptedUsageKey 后查询接受名；检索 StillImage，记录媒体署名/许可、记录类型及来源 | 区分活体照片、标本、图版；媒体许可单独读取，记录许可保留为独立字段 |

返回 `references_found` 表示找到了候选链接；查看实际图片后才能决定它们是否够画。`needs_identity` 列出匹配候选，先核对名称；`no_images` 或网络失败时换一个入口或专业条目，保留同一目标物种。HTTP 429、超时或服务错误后不反复请求同一接口。

## 从候选进入绘制

昆虫任务按 [昆虫实拍参考](insect-photo.md) 对齐生命阶段；iNaturalist 可加 `--adult` 检索已注释的成虫记录，随后逐张检查实际画面。

1. 打开参考页或来源记录，查看实际照片。优先选一张能说明主要姿态的参考，再按缺项补局部；一般 2–4 张有效参考即可，达到当前图的证据需求就停。仅有搜索文字或链接尚未看图时继续查看。
2. 同时核对 [形态依据](morphology-evidence.md)：植物可查植物智/植物志、Kew POWO；鸟类可查专业物种识别资料。只补影响本图的关键特征。植物的全株、叶序、花侧面与花果阶段分别找依据；鸟类对齐雌雄、年龄、季节羽及展开/收拢姿态。
3. 使用同一物种且条件相容的参考。照片中的品种差异、色型、畸变、遮挡与标本压制不直接拼成“典型个体”。当前图所需的地下或隐藏结构缺乏依据时先补查；需要用户决定的阶段或个体范围再追问。
4. 根据可见形态直接构形，参考复杂局部时沿用 [精细临摹与部件整理](editable-workflow.md)。已有素材可提供样式或经核对的通用部件；新物种的诊断特征、比例和连接按本种依据绘制。完成当前 SVG，无需先把物种加入网站分类。
5. 成稿按实际尺寸查看，逐项核对主轮廓、关键结构、斑纹、数量与编辑分组。交付 SVG 与实际预览，保留本次使用的来源记录及必要补绘说明。

照片查看、参考重绘、直接描摹和再分发分别处理。许可为空保留未提供，按源页核对；公开分发照片或其改编内容时遵循相应许可。参考页、来源和未授权图片留在任务目录；上传新 SVG 到素材库由用户的上传请求触发。

## 已验证范围

2026-09-15：iNaturalist 已查到戴胜（Upupa epops）和欧耧斗菜（Aquilegia vulgaris），GBIF 也查到后者；每组 4 张图片实际加载并查看。GBIF 的一组以叶片与枯果为主，iNaturalist 候选中可见花朵，体现了检索成功后仍需按绘图阶段选图。两个学名在本地现有素材清单中未找到。

已覆盖名称歧义、跨种照片排除、图片去重、图片许可保留、已有记录复用与预览文本转义的局部测试。数据库身份/记录不能替代科学与视觉验收。新的数据库先验证官方访问方式再接入，当前未实现自动调用植物智、POWO 或 Macaulay 的批量影像接口。
