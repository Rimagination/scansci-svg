# 植物画法

证据：本类 5 个样本已观察（2026-09-07）：竹、蕨、巨藻、稻、红树（ alias 见 [证据](ian-study.md)）；乔木见 [共同画法 A](drawing-grammar.md)。元素计数来自源码统计，形态来自渲染核对。下列数值为本地绘图建议，按当前对象与版面调整。

## 物种形态先核实

具体植物按 [在线形态核实](morphology-evidence.md) 查适用的植物志或专业物种条目；先核对名称与异名，再提取本图可见的生活型、叶序、单叶/复叶、叶缘/叶脉、着生方式及所需花果/根型。区分幼苗与成株、营养与生殖阶段、品种或季节差异，采用与当前植株阶段一致的特征。照片忠实稿保留其个体姿态，资料中的尺寸范围不直接变成照片个体的比例尺。

用户明确要求黑白线稿、植物志风格或分类学图版时，使用 [植物分类学黑白线稿](botanical-line-art.md)；该模式单独处理线条层级、点描/排线、诊断局部、比例尺和图版组织。

下方家族是既有样本的构形索引；物种条目与其冲突时按当前对象的证据调整，以适用的形态描述确定结构。成稿分别核对资料支持的识别特征与照片中实际可见的着生、比例和遮挡。

## 家族与部件树

| 形态家族 | 样本依据 | 部件树 |
| --- | --- | --- |
| 基生叶丛（禾草、作物、湿地草） | 稻 | 基部汇合区 → 叶片扇形展开 →（可选）顶部花序 |
| 节间柱（竹、甘蔗类似物） | 竹 | 主秆堆叠节间 → 节环 → 上部细枝 → 披针叶小扇 |
| 羽状复叶（蕨、棕榈类似物） | 蕨 | 冠丛 → 叶柄 → 中脉 → 小叶行（或整叶锯齿轮廓） |
| 藻体（海带类） | 巨藻 | 固着器 → 细长波浪柄 → 沿柄交替叶片 |
| 红树 | 红树 | 主干 → 枝端叶团 → 拱形支柱根落到水线 |

## 观察到的共同规则

- 披针形、带状单叶可用一条渐尖闭合曲线；宽度峰值和叶基形依对象调整。整体简化不意味着所有植物都可省略识别性叶脉或叶缘。
- 绿色以 2-4 个相近色成组；后层更暗、前层更亮；花序/穗/花用赭褐色与绿叶对比（稻穗 #997F3E）。
- 基生叶丛可“下聚上散”；沿茎生叶先定节位和叶序，各叶组接到对应节位。画幅服从新对象姿态。
- 缩小后先保证外轮廓和识别特征可读。数量参与物种识别、阶段判定或题目要求时，保留对应单位，用版面、局部放大或线宽调整改善可读性；可省略的后方叶片另作说明。

阶段组图先写出每幅实际可见的判定特征，再安排遮挡。例如玉米营养阶段按可见叶领计数，抽出的新叶尖不能替代叶领；绘完在交付尺寸下逐个核对叶片、叶鞘与叶领的对应关系。[阶段依据：Iowa State](https://crops.extension.iastate.edu/encyclopedia/corn-growth-stages)

## 各家族构造

### 叶片接合与编辑单元

- 先从参考确定叶基、叶柄及其着生节位，再绘制连接；有共用叶柄的复叶，公共叶柄、小叶柄、小叶及叶脉放入同一外层组，内部仍可单独编辑。共用的支撑茎留在叶组之外。根据叶基与着生关系区分单叶、复叶和小枝；无柄叶直接连接着生处。
- 已确认接合的实心填色部位，可让叶柄终端略进入叶基，避免抗锯齿亮缝；该表现技巧用于已经确认的着生关系。按通用构形约束检查接合与遮挡，遮挡区无需逐一补出不可见连接。
- 对已发现的孤立叶片，沿叶基回查到节位，局部调整柄端或叶片位置；修后对照参考确认叶柄与叶基实际接合。遮挡处的补绘注明依据；物种和叶序按原始资料核实。
- 联动检查示例：`python scripts/check_edit_units.py plant.svg --unit leaf-unit=petiole,blade,veins`。成员要求由参考与编辑需求确定，检查目标设为实际叶组及其叶柄、叶片和叶脉。检查后看实际渲染，必要时用副本平移该叶组验证。

### 基生叶丛（稻为依据）
- 叶片从同一基部区域呈约 90°-150° 扇形展开，先外拱后下垂；中部几片最长，两侧递减。
- 花序画在下弯的最长秆顶端：下垂弧线 + 沿线小颗粒簇；颗粒用对比色。
- 密度控制：小图标 5-9 片，中等 10-20 片；先排最外圈定轮廓，再补内圈。

### 节间柱（竹为依据）
- 主秆 = 2-4 根略锥形的竖柱；每柱由 6-12 个节间堆叠，节间是闭合段，交叠处画一条深色节环。
- 细枝从上部节位伸出，弧线外拱，枝端挂 3-9 片披针叶小扇；叶比节间窄长。
- 秆色偏黄绿，叶色更深的绿；后秆压暗，前秆提亮。

### 羽状复叶（蕨为依据）
- 小图：每片复叶 = 一条带锯齿/波浪边的闭合轮廓（小叶行整体并入轮廓），中心一条浅色中脉。
- 大图：中脉两侧逐对小叶，每个小叶一条闭合锥形路径；靠基部长、靠端部短。
- 冠丛由 4-8 片复叶放射构成，后层暗前层亮，整体圆形轮廓。

### 藻体（巨藻为依据）
- 柄 = 一条细长波浪线（闭合细锥形路径），占整株高度的 60-80%。
- 叶片沿柄交替着生，每个 = 小波浪/撕裂边闭合形，带短侧柄；越靠基部叶越少。
- 固着器 = 基部一团缠绕小块；巨藻样本可提炼暗黄褐/橄榄色方案，其他藻类依对象选色。

### 红树（红树为依据）
- 冠部沿用乔木叶团语法，但叶团更小、更碎（椭圆云团，每团独立路径），橄榄绿色。
- 该红树样本以支柱根为表现重点：3-8 条拱形锥形根跨越到水线，相互交叉留负空间；新对象的根型和起点依物种与可见参考确定。
- 根端按水线关系处理；支柱根、呼吸根等依物种和描述选用，不为装饰随意混加根型。

## 待验证的本地推演

- 棕榈/蒲葵的掌状裂叶、攀援藤本卷须、食虫植物捕虫器、松柏针束：按上述家族语法推演，标注为推演。
- 花/果的特写画法未在样本中学习；需要时先核实识别特征或如实说明按通用语法推演。
- 同一冠形可改色相/覆盖；落叶、开花、结果等阶段可能改变部件树。完整季节变化依据对应阶段的资料核对。
- 原创验证记录（2026-09-07）：玉米（节间柱 + 基生叶丛 + 雄穗组合）通过。首轮缺陷：叶短且对称导致读作针叶树，修正为长拱形垂叶后通过——印证"外拱后下垂"与端部散开两条规则是识别关键。
