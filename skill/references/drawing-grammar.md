# 构形语法：把对象特征变成可编辑矢量

以下是对三个 IAN 样本的观察和为本地绘图提炼的工程规则。数值建议与几何公式为本地绘图策略，按当前任务调整。

## 共同原则

小图里的辨识主要来自外轮廓、比例与标志性部件。先画轮廓、再画体块、最后画少量细节。空间主要由遮挡和明暗面表达；不需要每个物体都加粗黑边或复杂阴影。

让用户能修改对象特征：枝叶密度、树冠宽高、建筑层数、池体长宽等应对应少量几何决策。将这些特征组织成可独立选择和联动的部件。

## A. 乔木：骨架与叶团

春季树样本的核心是连续树干、可见分叉，以及前后遮挡的叶团。它没有逐片绘制树叶。后方叶团承托总体冠幅，树干居中或偏心，前方小叶团局部遮住枝端。

原创程序：

- 决定树冠长宽比、主干倾向、分叉高度和冠下净高；这些比装饰叶脉更影响树型。
- 树干使用闭合的渐细轮廓，根部较宽，主枝逐级变细。避免等宽 Y 字钢管形分叉；保留枝杈间的负空间。
- 叶团轮廓用有节奏的凸曲线连接。避免重复圆泡等距铺满整个树冠，也避免锯齿随机抖动。
- 后团大而暗，前团较小且亮；只有局部重叠处需要额外暗面。叶团数量随目标尺寸变化。
- 颜色变化服从树种/季节描述：春花、夏绿、秋色改变色相与覆盖范围，同时保留树干结构。
- 创作针叶树时可迁移“轮廓优先”的原则，使用有层次的锥形冠幅；此条为待验证的本地推演。

树的复杂度预算由识别性决定：缩小后若枝干消失，先加宽枝干；若树冠变成不自然的三角堆叠，先修冠形。整体比例修正后再补细节。

## B. 建筑：共享平面与重复构件

样本通过屋顶、明立面、暗立面和少量规则窗户就表达高层建筑。样本采用手绘式透视；需要精确投影时重新建立统一几何。

需要规整的原创科研图时，先选一个统一投影。用原点 O、两个地面方向 u/v 和竖直方向 z 建立几何；顶面和墙面共享顶点，避免各面单独估坐标。

一个立面的局部映射：

`P(s,t) = O + s*u + t*z, 0 <= s,t <= 1`

每扇窗的四角为 P(s0,t0)、P(s1,t0)、P(s1,t1)、P(s0,t1)。行列间距在立面坐标里控制，映射到画面后仍满足一致透视。需要透视消失点时改用同一平面单应映射，别混用投影。

- 屋顶最高明度，受光立面次之，背光立面更暗；饱和度克制，窗户与墙面保持足够对比。
- 同一立面的窗户共享尺寸、间距和边距。底排窗保留窗台与地面的距离，门的下沿贴墙底。
- 两层建筑不一定需要表现全部真实窗格；图标尺寸小就减少重复项，保持层数和入口可读。
- 烟囱、温室顶、传感器、光伏板等才是特定设施的识别特征；增加这些比增加几十扇窗更有效。

## C. 河流和剖面：共享岸线与层次

样本使用远窄近宽的水面、连续岸线、岸边浅色带、水下剖面和底质层。轮廓主要由长曲线构成，局部有薄描边和渐变；因此“所有元素都无描边、全平涂”不符合样本。

- 先画一条水系主走向，再建立两岸。远处河宽减小，近处逐渐展开；弯曲处平滑过渡，避免机械正弦波。
- 岸线同时约束土地边界、水面边界和岸边浅色带；复制同一边界数据或共享端点，避免白缝和层间错位。
- 剖面可分水面、水体、沉积层。深度渐变使用少量色阶，保留清晰层界；科学分层依资料确定。
- 过程箭头和文字只有在用户描述了相应含义时加入；不擅自把装饰图画成带科学结论的机制图。

## D. 向未见过的对象迁移

先找其基本体块：圆池=椭圆口+侧壁+内水面；温室=地面框架+重复拱肋+半透明或浅色覆膜；芦苇=细长弯曲茎+披针形叶+可选花序。

沿用遮挡、明暗、连续轮廓和重复规律，重新构造该对象的比例与路径。特殊仪器、指定物种、专业构造不明确时核实识别特征；将核实的结构特征落实到对应部件。

## 交付前的最小验证

渲染一次，对照描述检查“有没有画对东西”。检查外轮廓、狭窄负空间、部件遮挡、接合与缩略图识别性；确认 SVG 没有 image/script/foreignObject 或外链依赖，语义 ID 不重复。复杂路径可进一步检查自交；检查记录按实际执行项填写。
