# 上传到 ScanSci

适用：用户已生成或提供 SVG，并明确说“帮我上传 ScanSci”“上传这张图”“分享到 ScanSci 素材库”。完成一次明确的投稿，返回用户可以继续查看的结果。

## 选择文件与填写信息

1. 优先选择本轮已经交付、用户指明或确认满意的最新成稿。存在多份同等候选时，只询问要上传哪份；批量投稿按用户点名的文件范围执行。
2. 复用这份成稿已有的视觉和结构检查。文件有新改动时只检查受影响部分；服务端 SVG 校验仍决定文件能否接收。保留语义分组、文字及实际来源信息。
3. 根据图的内容填写标题、简短说明、分类和标签。署名取用户已确认的公开署名；说明保留影响理解的视角、简化或补绘信息。
4. 复用用户明确确认、适用于本件作品的默认许可和分享权限。缺少署名、许可或本件作品的分享权限时，将缺项合并为一次简短询问。参考图的作者、素材署名及上传账号分别记录。
5. 用户的上传指令已授权本次提交。文件和必要字段明确后继续执行；生成完成本身不触发投稿。上传后按服务端状态进入“我的投稿”或审核流程。

## 登录与授权

- 优先复用宿主已有的 ScanSci 连接器、上传工具或有效授权。首次需要授权时，使用该工具实际返回的 ScanSci 官方登录链接；用户在网页完成登录和授权，随后继续原投稿。
- 登录、默认署名和许可可在首次使用时一次设置；后续在适用范围内复用。用户撤销授权、凭据到期且无法续期时，再进行登录。
- 专用上传凭据由宿主的安全凭据存储管理，限定到投稿所需权限。凭据不进入对话正文、SVG、源码、Git 或交付包；用户在 ScanSci 侧可撤销授权。
- 只有网页投稿可用时，通过已登录的 ScanSci 页面填写和提交表单，沿用网页会话及同源校验。浏览器会话与专用客户端授权按各自实际能力使用，不导出会话 Cookie 充当上传令牌。
- 授权链接、令牌接口、刷新机制及素材详情地址均以已部署工具或服务返回为准。需要用户操作时说明具体一步，例如“请打开此链接，登录并允许本次客户端投稿”。

## 当前接入状态与接口

2026-09-15 已实测线上投稿服务和网页登录会话可用。公开素材在统一素材库展示，普通用户投稿显示“社区素材”徽章并进入审核；服务端确认的管理员上传直接发布，署名 ScanSci、许可 CC-BY-4.0。官方来源由持久字段 `official` 记录，客户端署名或自报身份不赋予免审资格。

通过当前官方网页提交；skill 尚未捆绑独立客户端授权。先读 `/api/symbols/session` 获取实际账号与 `can_review`，按真实响应处理。以下为已部署接口：

| 操作 | 已有本地接口 | 用途 |
| --- | --- | --- |
| 读取会话 | `GET /api/symbols/session` | 获取当前账号与审核权限 |
| 提交素材 | `POST /api/symbols` | 登录后提交 SVG 与元数据 |
| 查看本人投稿 | `GET /api/symbols?scope=mine` | 查找提交记录及状态 |
| 获取素材文件 | `GET /api/symbols/{id}/file` | 按权限访问 SVG |

这些接口当前使用网页会话；写入检查同源 Origin。后续专用客户端授权需要服务端实现，不能仅凭一次网页登录就假定命令行已获得授权。

投稿体沿用现有字段：`svg`、`title`、`description`、`author`、`category`、`tags`、`license`、`source_url`、`rights_confirmed`。`rights_confirmed=true` 对应用户实际确认且覆盖本件作品的分享权限。

当前投稿分类 ID 为 `plants`、`animals`、`biology`、`ecology`、`earth`、`laboratory`、`medicine`、`engineering`、`other`；网站浏览用的23个对象大类与149个绘图子类不直接作为投稿分类 ID。服务端目前接受 `CC0-1.0`、`CC-BY-4.0`；单件 SVG 上限200 KiB。接入时采用服务端最新约定。

## 提交与回执

- 正常成功：核对响应中 `ok`、素材 ID 和状态。普通投稿返回 HTTP 201、`ok: true`、`id`、`status: pending`；管理员直发返回 `status: published`。分别报告“等待审核”或“已公开”，并检查详情页显示实际署名和许可链接。
- 链接：优先使用服务端或网页返回的真实详情链接。仅有素材 ID 时报告 ID，并提供实际可用的“我的投稿”入口；文件接口与详情页分别标识。
- 重复文件（409）：查找本人已有投稿，返回核实到的记录。当前冲突响应仅含错误说明，不能假定响应带有旧素材 ID。
- 请求超时或响应中断：先查询本人投稿核实是否落库，找到原记录即复用。结果仍不确定时说明“提交结果待确认”，保留本次文件与信息，停止自动重发。
- 登录失效（401）：重新完成实际授权，再继续。权限不足（403）、配额限制（429）、服务未开放（503）按返回原因说明下一步；文件或字段错误（400）只修正具体问题后重试。
- 多文件任务逐件记录结果，保留成功的素材 ID；后续仅处理未完成项。

交付保持简短：素材标题、实际提交状态、可验证的入口或素材 ID，以及需要用户处理的具体事项。普通成功投稿无需再次询问是否提交或附长篇检查报告。
