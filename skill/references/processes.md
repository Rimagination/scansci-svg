# 过程画法

证据：本类 6 个样本已观察（2026-09-07）：输入箭头（nutrients）、输入输出模板（X in）、光合作用、混合（mixing）、浓度-高（叶绿素）、不确定性。记录见 [证据](ian-study.md)。下列数值为本地绘图建议，按当前对象与版面调整。

## 符号词汇

| 词汇 | 样本 | 核心观察 |
| --- | --- | --- |
| 锥形箭头 | nutrients 输入 | 大弧度弯曲箭头：一条闭合轮廓从宽尾收窄到三角头，标签沿曲线排布 |
| 波浪条带箭头 | 光合作用、X in | 竖向 S 波浪带状箭头，深色/反色条纹段叠加表达流动 |
| 螺旋流线 | mixing | 圆头粗描边弧线向内卷 + 独立小三角箭头 |
| 密度圆 | 浓度-高 | 粗描边大圆 + 浅色底 + 深色点阵，点密度表达浓度 |
| 修饰墨团 | 不确定性 | 厚描边云形团 + 矢量化符号（?、×、✓） |

## 观察到的共同规则

- 对象形态与空间关系依图像或结构资料核对；因果、调控、反应与输运依机制证据核对。按任务明确关系或适用机制文献确定源、汇、方向和条件；教学假设与已验证机制分别标明。对象本身的形态证据按 [对象特征与结构核实](morphology-evidence.md) 获取，作用方向与效果使用对应机制来源。
- 箭头是这些样本常用的方向符号；其他过程可用分区、前后状态或连接线表达。先明确用户描述的源、汇和关系，再选符号。
- 输入指向接收对象、输出离开源对象、交换可成对反向。页面上的上下方向及绿/蓝配色属于样本布局，含义由对象和图例确定。
- 箭身条纹可以增加视觉节奏；只有来源说明或用户图例明确赋义时，才将其解释为间歇、交换或其他机制。intermittent 变体记为待核对。
- IAN 把标签字母矢量化成路径；本地契约（见 SKILL.md）默认保留 `<text>` 以便用户改词，仅当用户要纯形状可移植时才矢量化。
- 颜色优先沿用用户图例；无图例时可用克制的对比色区分关系，颜色含义在图例中明确。浓度档位如采用同色相深浅，应标明编码含义。

## 各符号构造

### 锥形弯箭头（nutrients 为依据）
- 中心线 = 1-2 段贝塞尔大弧；宽度从尾到头约 1:0.4 锥度收窄；头部三角占全长的 15-25%。
- 头部与箭身可一条轮廓连成闭合形（样本即如此），阴影面用同色更深一档的窄条叠加。
- 标签沿箭头中心线排布（`<text>` + 旋转或 textPath）；字号约为箭头最大宽的 0.8-1.2。
- 原创验证已通过（沉积输入测试，2026-09-07）：单条闭合轮廓锥形箭头 + `<text>` 旋转标签 + 指向沉积层的落点；首轮臃肿轮廓已重画。

### 波浪条带箭头（光合作用为依据）
- 带 = 竖向 1.5-2 个全波的锥形闭合路径；成对使用时两条带左右并列、方向相反、颜色成对比。
- 条纹段 = 沿带身叠加 3-6 段深色/反色四边形，随波浪走向倾斜。
- 顶端标签放带外正上方（CO₂/O₂ 位置），不遮带。

### 螺旋与循环（mixing 为依据）
- 2-3 条圆头粗描边弧线按半径嵌套，最内圈 1.5-2 圈；端点接独立小三角箭头（描边色同弧线）。
- 循环图（再生、循环利用语义）用椭圆轨道 + 均布 2-4 个箭头（推演，样本只核对了螺旋）。

### 密度与浓度（高叶绿素为依据）
- 大圆描边宽约为半径的 8-10%；底色浅、点色深且同色相。
- 档位：high=满铺 15-30 点、low=3-8 点（low 档已通过原创验证，2026-09-07）、intermittent=点呈斑块或半圆缺口分布（intermittent 的精确画法未核对，按 high 档推演并标注）。

### 修饰符号（不确定性为依据）
- 墨团 = 3-6 个凸弧拼成的云状闭合形 + 厚描边 + 单色渐变；符号（?、×、✓）居中，白色或深色反衬。
- 方向性修饰（增/减箭头、引入种标记等相册条目）未学习，按墨团+符号语法推演。
