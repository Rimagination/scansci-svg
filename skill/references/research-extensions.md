# 科研扩展画法

证据：仪器类 4 个样本已观察（2026-09-07）：显微镜、野外台站符号、气象塔、箱式采泥器。细胞/分子与跨尺度构图小节为待验证的本地推演。记录见 [证据](ian-study.md)。下列数值为本地绘图建议，按当前对象与版面调整。

具体任务先按 [对象特征与结构核实](morphology-evidence.md) 选对应来源：仪器查厂家型号、版本/选配及接口/尺寸图；组织查物种、部位、切面和状态；小分子核对化学连接、键级、电荷与立体化学，大分子三维表达查结构编号、构象、生物学装配体及缺失区域。团块语法用于概括示意；精确结构按已有数据构形。通用装置保持通用层级，内部结构依对应型号资料绘制。

## 观察到的规则

- 金属灰三档：亮灰（受光面）→ 中灰 → 深灰（暗面/控制件），偏冷；黑色只给旋钮、缆绳等重音。
- 功能体块先于细节：底座、立柱、臂、台面四类体块立住剪影，识别细节（物镜数、锅面角度、天线）再叠加。
- 桁架/塔类用线构图：主柱 2-3 条竖线 + 交叉斜撑，节间渐窄；拉线 3-6 根细线放射，末端接地。
- 台站类组合直接复用既有画法：建筑立面映射（[共同画法 B](drawing-grammar.md)）+ 锅面弧 + 天线杆。

## 仪器构造程序

1. 定部件树：底座 → 立柱/臂 → 功能端（镜筒/锅/采样口）→ 控制件 → 缆线。
2. 每个体块一个闭合路径 + 1-2 档明暗面；转角处用窄条暗面，不画外描边。
3. 控制件（旋钮、阀、开关）= 小圆/小方块，深色，数量 2-6 个；多于 6 个就并组。
4. 缆绳/管线接入实际接口点，垂度可用一段弧。等宽线明确 stroke 和 fill="none"；渐细线用闭合轮廓，避免开放路径隐式填充造成三角块。

## 细胞与分子（全部推演，无样本核对）

以下仅是待验证的本地绘图策略。先识别用户要表达的细胞类型或分子层级，核对影响科学含义的特征后再画；通用示意注明其层级。

- 根据细胞类型确定是否具有细胞壁、核及相应细胞器。绘图中的两条轮廓线需要说明表达的是厚度、双层结构还是不同边界。
- 细胞器保持"一器一形一色"：内质网=波带叠层、高尔基=弧形扁囊垛、囊泡=小圆；每个用局部高对比色与胞质底色区分。
- 分子表面 = 相邻圆并集形成的团块轮廓；链状分子 = 沿折线布单元（复用微生物链语法）；催化界面 = 团块 + 局部缺口 + 箭头对接（复用 [过程](processes.md) 箭头语法）。
- 尺度表达：有标定或尺寸依据时按比例绘制；概括布局标为示意。

## 跨尺度机制构图（推演）

- 分层构图：每层一套对象组（流域块体 / 根际截面 / 细胞切面）。放大关系用取样框、放大连线或局部视窗；过程箭头另用明确语义，避免把视觉缩放误画成物质输运。
- 层内各自遵守对应指南的投影与完成度，不跨层混模式；跨层箭头统一用过程箭头语法。
- 同一机制在两层重复出现的要素（如水流、养分）用同色标注，建立视觉对应。
- 此类构图未见 IAN 样本，属于把多类画法组合的本地策略；交付时标注"组合推演"。
