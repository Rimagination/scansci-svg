# 地球、环境与治理 SVG 类别

按对象或场景选对应行，再组合相邻领域。几何与分组为本地构形方案；来源列映射 [IAN 相册](ian-albums.md)。`—` 表示独立扩展。整图先确定对象和关系，构形沿用 [环境画法](ecosystems.md)、[共同画法](drawing-grammar.md) 与 [过程画法](processes.md)。

2026-09-08 核对的专业入口：[USGS 水循环](https://www.usgs.gov/water-science-school/water-cycle) 用于水库、通量及地表地下联系；[EPA 废水研究](https://www.epa.gov/water-research/wastewater-research) 用于处理系统、污染物和监测主题。具体地点、层厚、物种、工艺参数按 [特征核实](morphology-evidence.md) 补齐对应资料。
