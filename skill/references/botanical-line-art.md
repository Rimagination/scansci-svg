# 植物分类学黑白线稿

用于用户明确要求黑白植物线稿、植物志图版、分类学插图或墨线植物图时。目标是让成稿在无颜色条件下清楚表达对象身份与鉴别特征，并可作为 SVG 继续修改。普通植物示意和仅去色的现有图不自动套用完整图版结构。

用户指定“墨线图”时，进一步采用 [先生图后重建流程](botanical-ink-reconstruction.md)，保留该风格名称。本页的形态证据、连接与黑白笔法约束仍适用。

## 先确定图件类型与证据

- **单株/单部件线稿**：按用户点名范围绘制，全株、枝条、叶、花或果只做所需部分。
- **分类学图版**：先列出本图必须显示的鉴别特征，再安排习性图、叶序/着生、花果、种子和必要的解剖或放大局部。局部数量随物种特征和文稿需要确定。
- **植物—土壤或生境剖面**：可沿用黑白轮廓、点描与排线语法；根系类型、地下深度、土层和邻近关系依物种资料或现场数据确定。示例图只支持风格选择，不支持具体物种结构。

具体分类单元先按 [对象特征与结构核实](morphology-evidence.md) 核对接受名、异名、发育阶段和需要落图的性状。植物志或分类学描述约束器官结构、数量、着生与尺寸范围；有记录的标本、解剖照片或实拍约束个体姿态及可见细节。多个个体的特征组成一张概括图版时，保留各局部的来源关系，避免把不同阶段或不同个体拼成一个未经说明的单株。

## 黑白线条语法

本地安装包含 [植物墨线参考板与原图索引](botanical-ink-reference.md) 时，先实际看总览，再查看与本图相关的原图细节，选定轮廓层级、点描分布、排线方向和留白方式。总览用于整体风格，原图用于细线判断；物种身份、器官数量与着生仍按目标物种证据核对。参考文件缺失时沿用下述规则与用户当前提供的图，说明实际查看范围。

- 默认使用纯黑线和无填充形体；白色来自底色或留白。层次由线宽、线密度、点描和排线建立。灰色填充、渐变与彩色只在用户或出版规范明确允许时使用。
- 线条形成可读层级：外轮廓和切面边界最强，主脉/主轴与器官接合次之，次级脉、毛被、表面纹理和点描更细。具体线宽按最终版面与输出设备调整，不跨期刊固化数值。
- 轮廓在真实遮挡处中断；器官接合、叶基、花梗和分枝节点保持连续。不要用装饰性笔触掩盖着生关系，也不要让密集排线封死狭小负空间。
- 点描表达柔和体积、细小毛被或表面质地；短排线表达转折、凹陷和切面；规则结构用可数、可追踪的线。纹理密度服从形态与可读性，不能替代叶脉、裂片、齿、毛或种脊等诊断结构。
- 同套图版统一轮廓层级、点描颗粒、排线方向和标签样式。局部放大保留与全株对应的结构方向，允许旋转时用标注或构图消除歧义。

## 植物特征怎样落图

先画生活型和主轴，再按证据安放节、分枝、叶序和器官着生，最后补诊断细节。逐项核对：

- 叶：单叶/复叶、叶柄与叶基、叶序、叶形、叶缘、脉序、上下表面差异和毛被；复叶的小叶与小枝通过柄和芽的位置区分。
- 花序与花：花序类型、花的朝向和着生、苞片、萼/花冠/雄蕊/心皮的数量与合生关系；需要时用正面、侧面、纵剖、横剖或展开图分别表达。
- 果实与种子：成熟阶段、开裂方式、宿存结构、种子数量、着生点与表面纹饰；截面须与外形对应。
- 根与地下器官：主根/须根、根茎、块茎、鳞茎及其连接依材料和描述绘制。缺少地下证据时省略或明确标为概括，不能从地上生活型推断根型与深度。
- 尺寸与数量：诊断性的计数保持准确；尺寸范围可指导相对比例。比例尺只使用对应标本、照片标定或实测数据，多个倍率的局部分别给出尺度或明确放大关系。

遮挡妨碍鉴别时，调整枝叶展开角度或增加独立局部；保留合理的植物姿态，不为展示所有性状把单株扭成不自然结构。无法在同一阶段共存的花果可作为分立局部展示并注明阶段。

## 图版构图与 SVG 组织

- 分类学图版通常以习性图或代表枝条为视觉主项，诊断局部围绕空白区布置；分图字母、引线、名称和比例尺不压住轮廓及关键纹理。
- 线稿与试稿默认先不加 A/B/C 或 a/b/c 等分图字母；用户明确要求或进入正式组图排版时再添加，并在图注逐项对应器官、视角和阶段。教学或解剖说明图按需把名称布置在主体周围，用短而清楚的引线直接指向结构。单图采用一套主要标注系统，避免字母、长标签和密集引线同时争夺空间。
- 可把花期枝、果期枝、叶片近轴面/远轴面、根或基生茎及生殖器官拆成独立视图，以大块留白建立阅读顺序。是否成对展示及局部数量由鉴别需求决定；每个独立倍率的视图配对应比例尺，图注写清方向、阶段和解剖方式。
- 习性图负责生活型、分枝、叶序和总体姿态；局部图负责在主图尺度下难以辨认的毛被、脉序、花部、果实、种子和剖面。局部图应补足诊断信息，避免只是重复放大主图已有内容。
- 每个习性图、器官局部、剖面、比例尺和标签使用具名组；器官内部可按轮廓、叶脉/结构线、点描/排线继续分组。重复纹理可以复用定义，交付前确认单个局部仍可编辑且导入目标软件后不丢失。
- 默认交付透明背景 SVG 与白底 PNG 预览；出版方要求白底、线宽、字体、图宽或纯 1-bit 输出时按其规范覆盖默认值。文字保留为可编辑文本，拉丁学名的斜体及命名人格式依稿件要求处理。
- 改编既有图版时区分形态证据与图形复用。原创建路径可参考事实；直接描摹或改编受版权保护的构图与笔触前核对许可，并保留来源和改编说明。

## 成稿验收

在目标印刷/页面尺寸查看实际渲染，并核对：

1. 接受名、阶段及图中个体/局部的来源适用；鉴别特征能在图中逐项定位。
2. 叶序、分枝、器官数量、着生、合生/离生、剖面对应和花果阶段一致。
3. 缩小后外轮廓、主脉和细部层级仍清楚；密集叶片、毛被和排线没有糊成黑块，细线没有消失。
4. 全图无意外颜色或灰块；比例尺、分图字母、引线与标签可读且对应正确。
5. SVG 的全株、局部、纹理、比例尺和文字可分别选择；PNG/PDF 等目标格式保留细线与点描。

交付说明列出本图保留的鉴别特征、各局部的依据、实质简化或概括，以及仍缺少证据的具体部位。
