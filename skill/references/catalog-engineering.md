# 材料、工程、实验与航天绘图类别

按对象选择子类，再将表中的部件组织为可独立移动、改色和改字的组。组合图按功能连接多个对象；设备外形、材料内部结构、实验操作和数据结果分别组织。构形方法见 [科研扩展画法](research-extensions.md)，结构核对见 [对象特征与结构核实](morphology-evidence.md)，反应、能量与输运关系见 [过程画法](processes.md)。

专业入口于 2026-09-08 实际访问：

- [RCSB PDB](https://www.rcsb.org/)：定位分子结构、配体及生物学装配体，用于材料与生物界面中的结构对象。
- [美国能源部：燃料电池](https://www.energy.gov/cmei/fuels/fuel-cells)：定位电极、电解质及燃料、电荷的通路说明。
- [Agilent 液相色谱](https://www.agilent.com/en/product/liquid-chromatography)：定位仪器家族、组件和产品资料。
- [JEOL 扫描电子显微镜](https://www.jeol.com/products/scientific/sem/)：定位电子显微镜产品及对应技术资料。
- [NASA 太阳系探索](https://science.nasa.gov/solar-system/)：定位天体、探测任务、航天器及天文观测入口。

这些入口用于按任务找到具体条目。绘制特定材料时使用其组成、结构编号或实验资料；绘制特定设备时再核对型号、配置、接口和尺寸图。下表记录类别与构形方案；单图的科学、视觉及编辑验证随实际制作记录。IAN 相册 ID 对应 [来源分类](ian-albums.md)，`—` 表示本地领域扩展。
