# 树麻雀：照片 → SVG

本案例依据下列真实照片重新绘制，保留右向侧视、站立姿态与主要识别斑纹；省去石台和背景，将羽毛纹理概括为可编辑色面和细线。SVG 与照片使用同一画幅，便于对照轮廓和部位。

- 作品：Tree Sparrow August 2007 Osaka Japan.jpg。
- 摄影：Laitche，2007 年 8 月 31 日，日本大阪。

## SVG 重建

- 文件：`sparrow-rebuilt.svg`；`rebuilt-preview.png` 是白底展示预览，SVG 本身背景透明。
- 制作与署名：ScanSci，AI 辅助绘制，2026-09-15。
- 许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。建议署名“ScanSci；照片参考：Laitche（公有领域）”。
- 全鸟与头、喙、眼、颊斑、喉斑、翼、尾、腿足分别组织；形状为原生矢量路径，未嵌入照片。
- 形态核对复用项目[鸟类照片规则](../../../skill/references/bird-photo.md)中已记录的 Cornell/Audubon 资料：栗色头冠、白颊内黑斑、黑喉斑和短粗喙。年龄、性别和亚种未判定。
- 这是简化的自然插画：羽毛边界和细纹经过概括，局部比例与照片仍有差异，未经鸟类专家审定。
